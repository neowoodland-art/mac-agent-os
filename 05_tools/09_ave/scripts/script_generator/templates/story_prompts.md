# ScriptGenerator — 剧本创作指引 v1.0

> 用途：当我（Claw）根据灵感创作剧本时，按照此格式输出，ScriptGenerator 自动注入流水线

---

## 输出格式（我创作时的标准模板）

创作完剧本后，按以下结构输出 **segments 列表**：

```python
segments = [
    {
        "scene": "分镜标题/场景名",           # 简洁，如"清晨的咖啡馆"
        "description": "场景视觉描述",         # 15-40字，描述画面内容
        "dialogue": "旁白/角色台词",           # 格式: "(旁白) ..." 或 "角色名: ..."
        "emotion": "情绪标签",                 # 温暖/专注/愉悦/燃/治愈/悲伤/紧张...
        "duration_sec": 8,                     # 3-12s，通常6-10s
        "camera": "镜头类型",                  # wide_shot / medium_shot / close_up / tracking / aerial / pan / dolly
        "transition": "转场效果",              # cut / fade_in / dissolve / zoom_in / wipe_left
    },
    # ...更多分镜
]
```

## 我创作时遵循的准则

### 1. 总时长控制
- 目标视频长度 30-180s
- 每个分镜 5-10s（复杂场景可到 12s，快速节奏 3-5s）
- 分镜数 = 目标时长 / 平均分镜时长

### 2. 叙事结构
```
开场(15-20%): 建立场景/引入角色 → 主要自然过渡
发展(50-60%): 核心内容展开 → 随情绪变化切换
收尾(15-20%): 情绪收束/升华 → 自然淡出
```

### 3. 镜头运用
| 镜头 | 用途 |
|:----|:-----|
| wide_shot | 建立场景、环境展示 |
| medium_shot | 角色互动、日常动作 |
| close_up | 情绪特写、细节展示 |
| tracking | 跟随移动、场景导览 |
| aerial | 全景建立（数字人也可） |
| pan | 场景平移展示 |
| dolly | 推进/拉远，聚焦或展示全景 |

### 4. 情绪节奏
- 同一情绪分段持续 2-4 个分镜，不要频繁跳跃
- 情绪变化需要自然过渡：温暖→专注→愉悦→满足
- 燃系视频保持高能量，治愈系保持舒缓节奏

### 5. 对话 vs 旁白
- 旁白: `"(旁白) 叙述内容"` — 适用于说明性、情感性内容
- 角色台词: `"角色名: 说话内容"` — 适用于有角色互动的场景
- 纯音乐卡点视频：dialogue 可为空字符串

### 6. BGM 风格匹配
- 治愈系: 温和情绪，舒缓节奏
- 燃系: 高能量，短分镜(3-5s)，快切
- 搞笑: 轻快节奏，夸张描述
- 情感: 长分镜(8-12s)，细腻描述

## 使用流程

```
[用户给灵感]
    ↓
[我创作剧本 + segments 列表]
    ↓
[调用 ScriptGenerator.format_and_inject()]
    ↓
[segments 转化为标准脚本 → 注入 PipelineController]
    ↓
[自动触发 Gate 1 审核]
```
