# 角色定妆照 Prompt 体系 V3
>
> 版本: 3.0 | 最后更新: 2026-05-29
> 用于 Kling / 即梦 / Midjourney 等 AI 图像生成工具
> 完整10层模块化提示词框架 + 面部五官详细描述词典

---

## 一、核心理念

### AI 角色生成的金科玉律

1. **AI 无记忆** — 每次生成都是独立的概率过程，必须主动约束
2. **先建角色圣经** — 生成前定义15-20个具体物理属性
3. **描述符优先级** — 提示词的出现的顺序 = AI 的重视程度
4. **角色先行** — 角色描述**必须**出现在场景和风格之前
5. **只改一个变量** — 每次只允许改变场景或构图中的一个

### 提示词黄金公式

```
[角色身份锚点] + [区分性特征] + [场景上下文] + [姿势/表情] + [光镜头修饰符]
```

### 三大固定模块

| 模块 | 内容 | 变化规则 |
|:----|:-----|:--------|
| 角色块 | 外貌+服装+表情倾向 | **不可修改** |
| 场景块 | 环境+时间+色调 | 每场景改 |
| 风格块 | 光线+镜头+负面约束 | **不可修改** |

## 二、10层模块化角色描述系统

### 层级总览

```
L0 身份层     → 姓名/性别/年龄/种族/世界观     (最优先, AI最重视)
    ↓
L1 面部轮廓   → 脸型/下颌线/颧骨/额头
    ↓
L2 五官细节   → 眼睛(形/色/神) / 眉毛 / 鼻子 / 嘴唇
    ↓
L3 头发层     → 发型/长度/颜色/质地/发际线
    ↓
L4 皮肤妆容   → 肤色/肤质/底妆/特殊标记
    ↓
L5 体型姿态   → 身高/体型/肩宽/站姿
    ↓
L6 服装配饰   → 上装/下装/外套/鞋/配饰
    ↓
L7 神态表情   → 微表情/眼神/情绪基调/气质
    ↓
L8 光线镜头   → 光型/色温/镜头/景深
    ↓
L9 背景场景   → 环境/背景色/季节天气    (最次优先)
```

## 三、微表情分类体系

### 基础表情库（可组合使用）

| 表情 | 关键词 | 面部细节 |
|:----|:-------|:---------|
| 平静 | 中性、平静、从容 | 面部放松，嘴角自然，眼周无纹 |
| 微笑 | 淡淡微笑、温暖笑意 | 嘴角上提，眼轮匝肌微收，苹果肌微抬 |
| 开怀大笑 | 大笑、开心、灿烂 | 张嘴露齿，眼眯起，眼角鱼尾纹 |
| 专注 | 专注、凝视、认真 | 眉头轻蹙，目光固定，嘴唇微抿 |
| 沉思 | 思考、内省、深沉 | 眼神下移或放空，眉头微锁 |
| 坚定 | 坚定、决然、刚毅 | 目光锐利，下颌微收，嘴唇紧抿 |
| 惊讶 | 惊讶、震惊、意外 | 眉峰上提，眼睁大，嘴微张 |
| 愤怒 | 生气、怒视、愠怒 | 眉头压低，眼神锐利，嘴角下拉 |
| 悲伤 | 忧伤、失落、哀愁 | 眼神垂落，嘴角微下，眉头轻蹙 |
| 温柔 | 温柔、柔和、宠溺 | 眼角含笑意，神情松弛，嘴角上扬 |

### 微表情使用规则
- 组合使用: `神色平静从容，眼含笑意，嘴角微微上翘`
- 避免单一: 不要只用"微笑"，要说明微表情的程度和部位
- 一致性: 眼神 决定角色情绪可信度的70%

## 四、组装规则

### 最终 Prompt 结构

```
[角色描述块(10层)] + [场景描述块(每场景改)] + [镜头指令块(每场景改)]
```

```text

{脸型}，{下颌线}，{颧骨}。

```

## 六、平台差异提示

### Kling（可灵）提示词技巧
- **用中文**效果更好，关键角色特征放在最前面
- Kling 对人名/角色名的概念不强→用特征描述代替名称
- Kling 对"网格布局"理解不稳定→网格方案建议用单格逐张生成后拼接
- 固定 seed 可显著提升同一角色的一致性
- 建议使用 I2I（图生图）模式提升5-15%一致性

### 即梦提示词技巧
- 理解"网格"概念较好，适合直接生成多宫格
- 支持角色参考图功能
- 对光线描述更敏感

### MidJourney 提示词技巧
- 使用 `--cref` 参数 + 角色参考图
- `--cw 0-100` 控制角色一致性的权重
- 使用 `--sref` 控制风格一致性

### 通用规则
- 角色描述用中文，技术参数用英文（`--ar 9:16`）
- 固定种子：同一个角色的所有生成使用相同的 seed
- 角色描述块不做任何改动地在所有 Prompt 中复用
