## 一、项目背景

### 1.1 目标

为 AVE 视频工厂提供高质量的 AI 生成视频素材，替代 Pexels 免费素材。
每期口播视频需要 12 段素材，每段 5-10 秒竖屏视频。

### 1.2 为什么选即梦网页版

| 方案 | 每段5秒成本 | 一期12段 | 备注 |
|:-----|:----------:|:--------:|:-----|
| Pexels 免费素材 | 0元 | 0元 | 画面静态，观感差 |
| 腾讯云混元 API | 1.8-3.6元 | 21.6-43.2元 | 后付费，贵 |
| **即梦网页版会员** | **0.22-0.37元** | **2.6-4.4元** | **VIP 可用 1080p，便宜** |
| 即梦 CLI | 同会员积分 | 同左 | **VIP 模型 CLI 不支持，720p 限制** |

**结论**：即梦网页版会员(¥79-649/月)性价比最高，但需通过 Peekaboo 自动化操作网页。

### 1.3 备选方案对比

| 方案 | 结果 | 原因 |
|:-----|:----:|:-----|
| Dreamina CLI 直接调用 | ❌ 放弃 | CLI 免费版锁 720p，VIP 模型不支持 |
| Buddy-cloud.py (腾讯云) | ✅ 可用 | 1080p 可用，但成本是即梦网页版的 5-10x |
| CloakBrowser Playwright 自动化 | 🔧 备用 | 需处理反爬/登录态，不如 Peekaboo 直接 |
| Peekaboo GUI 自动化 | ✅ **主方案** | 基于视觉识别，即梦不管怎么改UI都能用 |

## 三、即梦首页页面结构

### 3.1 侧边栏（左）

| 图标按钮 | 文字 | 功能 |
|:--------|:----|:-----|
| 💡 | 灵感 | 默认首页，直接输入 prompt |
| ⚡ | 生成 | 各类生成任务入口 |
| 📦 | 资产 | 历史作品 |
| 🎨 | 画布 | 编辑/合成 |
| ❓ | OCTO | 未知功能 |

底部：开通会员 | 积分(80) | 头像(登录后显示) | 通知🔔 | CLI 介绍

### 3.2 主输入区（中）

大输入框（类智能体对话框），包含：

| 元素 | 位置 | 说明 |
|:-----|:----|:-----|
| + 添加文件 | 输入框左上角 | 图生图/图生视频等 |
| 智能体模式(Agent) | 输入框下方左 | 默认模式，自动判断输出类型 |
| 自动/生成偏好 | 模式按钮旁 | 可设图片/视频、比例、模型版本 |
| [使用技能] | 模式按钮区 | 剧情短片、电商套图、海报设计等 |
| [@] | 模式按钮区 | 指定主体/人物 |
| 🎤 麦克风 | 输入框右下角 | 语音输入 |
| ↑ 发送箭头 | 输入框右下角 | 灰色→变亮（输入内容后） |

### 3.3 模式切换弹窗

点"智能体模式"可切换：

| 模式 | 用途 |
|:-----|:-----|
| 图片生成 | 文生图 |
| 视频生成 | 文生视频（本方案目标模式） |
| 数字人 | 数字人出镜 |
| 配音 | 语音合成 |
| 动作模仿 | 动作驱动 |

### 3.4 自动/生成偏好设置

| 设置项 | 可选值 |
|:-------|:-------|
| 输出类型 | 图片 / 视频 |
| 比例 | 21:9 / 16:9 / 9:16(竖屏) / 等 |
| 模型版本 | 图片4.0 / 3.0 / 等 |

## 四、完整操作路径（已记录 5/7 步）

```
① 首页（灵感Tab，Agent模式）
   状态: 输入框空，发送按钮灰色
   操作: 输入 prompt
   ↓
② 输入 prompt 后
   状态: 发送按钮由灰变亮，其他无变化
   操作: 按回车 或 点发送箭头
   ↓
③ 进入对话模式
   状态: AI 开始分析 prompt
   ↓
④ ⚠️ 模型不可用降级（每次都会触发）
   状态: 弹出积分确认框
     ├─ "消耗 X 积分，确认继续生成"
     ├─ ⭐ "本次对话不再确认"（鼠标悬浮出现小按钮，可勾选）
     └─ 点确认 → 扣积分
   ↓
⑤ 生成排队
   状态: 输入框右上方出现生成状态条
   内容区: "排队中" → "生成中"
   结果区: 图片占位框 + "以上内容由AI生成本次消耗X积分"
          + [重新生成] 按钮 + [引用作品] 按钮（双引号）
   ↓
⑥ 生成完成
   状态: ?（待下次记录）
   下载方式: ?（待下次记录）
   ↓
⑦ 保存到 AVE cache
   ⏳ 待实现
```

### 4.1 关键交互细节

- **积分确认**: 每次生成都会弹出，可勾选"本次对话不再确认"
- **模型降级**: Agent 模式自动选 VIP 模型 → VIP 不可用 → 降级普通模型 → 重新确认积分
- **排队等待**: 生成任务进入队列，排队时间不定（上次卡住未完成）
- **发送方式**: 回车键 或 点发送箭头

### 5.1 核心工具

- **Peekaboo v3.1.2**：macOS GUI 自动化（视觉识别 + 点击 + 输入）
