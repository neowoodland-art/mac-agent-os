## 一、背景

前次会话完成 AudioLine→AVE Phase 1 四路集成（T169-T172）后，转向**体育主题角色一致性图片生成**。此前 AVE 的角色管线以漫剧/日常场景为主，缺少体育/运动场景的专项能力。

## 二、问题定义

| 维度 | 说明 |
|:----|:-----|
| 目标 | 生成带角色一致性的体育/运动主题图片，男女角色各一 |
| 渠道 | Kling 文生图 + Kling I2I 变体（现有 AVE 基础设施） |
| 场景 | 跑步、篮球、足球、健身等多运动姿态 |
| 核心挑战 | 高动态姿态下保持面部/体型/服装一致性 |
| 输出形式 | 定妆照 + 多姿态参考图 → 可用于 AVE 视频生成 |

---

## 三、三层工作流策略（全网调研结论）

AI 角色一致性主流方案分为三个层级，底层性价比最高：

| 层级 | 方法 | 一致性 | 成本 | 学习曲线 | 推荐场景 |
|:----|:-----|:------|:----|:--------|:--------|
| **轻量层** | 单图引用 + 提示词纪律 | 60-70% | 低 | 低 | 快速试错/概念探索 |
| **受控层** | Grid Method + I2I 变体 | 75-85% | 中 | 中 | **体育角色首选 ← 我们在这里** |
| **训练层** | LoRA 微调 | 90-96% | 高 | 高 | 长期 IP / 商业级项目 |

**体育角色推荐路径**：先走受控层（我们已有 character_sheet.py 的 Grid Method + Kling I2I），待角色确认为长期资产后再升级 LoRA。

## 六、角色一致性图库方案

### 6.1 方案架构

基于现有 Grid Method 改造：

```
第一阶段：定妆照（2x3 → 3x3 升级）
  ┌─────────────┬─────────────┬─────────────┐
  │ 全身正面      │ 全身侧面      │ 全身 3/4     │
  │ （标准站姿）  │ （侧身）      │ （斜45度）    │
  ├─────────────┼─────────────┼─────────────┤
  │ 面部中性     │ 面部微笑     │ 面部发力     │
  │ （标准表情）  │ （亲和）     │ （运动表情）  │
  ├─────────────┼─────────────┼─────────────┤
  │ 运动姿态 A   │ 运动姿态 B   │ 运动姿态 C   │
  │ （如运球）   │ （如投篮）   │ （如防守）   │
  └─────────────┴─────────────┴─────────────┘

第二阶段：Kling I2I 变体生成
  各单格 → 3 变体 → 总计 18+ 参考图

第三阶段：注册到 CharacterRegistry
  定妆照 + 裁剪图 → 注册 → character_locker 全片注入
```

### 6.2 生成流程

```
1. 用 character_sheet.py（改造后）生成 3x3 网格定妆照
   ├── Kling 文生图 (kling-v1, 3:2 比例)
   ├── 裁剪 9 张单格（extract_cells 升级版）
   └── 存入角色库

2. 对"运动姿态"和"面部-运动表情"格执行 Kling I2I 变体
   ├── 每个 source → 3 变体
   └── 增加场景多样性（室内/室外/不同光线）

3. 注册到 CharacterRegistry
   ├── 网格图 → reference_images.grid
   ├── 面部中性 → reference_images.portrait
   ├── 表情 → reference_images.expressions
   └── 运动姿态 → reference_images.sport_poses （新字段）
```

### 6.3 所需改动

| 改动点 | 文件 | 工作量 | 说明 |
|:------|:----|:------|:-----|
| Grid Method 升级 3x3 | `character_sheet.py` | 中 | 裁剪行列数、CELL_NAMES、GRID_PROMPT 模板 |
| 新增体育 prompt 模板 | `prompts/character_sheet_prompts.md` | 小 | 追加 3x3 模板 + 运动场景示例 |
| Registry 新字段 | `character_registry/registry.yaml` | 小 | 角色 schema 增加 sport_poses 字段 |
| 多姿态变体批量生成 | `character_sheet.py` | 中 | 对多个 cell 批量跑 I2I |

## 八、风险与备选

| 风险 | 概率 | 缓解方案 |
|:----|:----|:--------|
| Kling 文生图 3x3 网格排版不准 | 中 | 备选：先出 2x3 再手动补运动姿态格 |
| I2I 变体人脸偏离 | 中 | 重复调用强制 seed / 人工筛选最佳变体 |
| 运动姿态下服装细节丢失 | 低 | 描述块中强调颜色/logo/纹理细节 |
| API 调用费用 | 低 | 每张定妆照 ~¥0.3，总成本可控 <¥10 |
