# AVE v2.0 架构重构方案

> **版本**: v2.0 (草案)
> **创建**: 2026-05-15
> **核心理念**: 结果推导 — 从目标视频反推创作链路
> **知识基础**: AI视频提示词系统教科书（19章）+ 全网调研

---

## 一、核心差距分析

### 当前 AVE v1.x 的问题

| 维度 | 现状 | 目标 |
|:-----|:-----|:-----|
| **输入** | 仅支持 YAML 或 纯文本 | 支持小说/故事/RSS/链接等多种输入 |
| **分镜** | 直接 LLM 解析，无结构化分镜 | 四步工作流：场景拆分→镜头分配→风格定调→prompt生成 |
| **风格控制** | 无 | 统一的风格锚点 + 角色一致性 |
| **素材来源** | Pexels(单一) | Kling API / 百炼 / 即梦网页版 / Pexels / 数字人 多引擎 |
| **提示词** | 简单关键词搜索 | 五要素结构化提示词 + 正向/负向 + 权重控制 |
| **输出** | 1080p mp4 仅口播类型 | 支持宣传片/故事片/TVC/漫剧等多类型 |

## 二、五层架构设计

```
┌─────────────────────────────────────────────────────────┐
│ Layer 1: 输入层  (文案/小说/RSS/链接 → 结构化内容)      │
├─────────────────────────────────────────────────────────┤
│ Layer 2: 分镜引擎 (LLM拆分场景→分配镜头→风格定调→生prompt) │
├─────────────────────────────────────────────────────────┤
│ Layer 3: 素材生产 (Kling/百炼/即梦/Pexels/数字人 多引擎)  │
├─────────────────────────────────────────────────────────┤
│ Layer 4: 合成引擎 (TTS + KenBurns + BGM + 字幕 → mp4)  │
├─────────────────────────────────────────────────────────┤
│ Layer 5: 输出层  (1080x1920.mp4 → 抖音/快手/视频号)      │
└─────────────────────────────────────────────────────────┘
```

### Layer 1: 输入层

```
输入类型:
├─ YAML脚本    → 直接解析（当前已有）
├─ 纯文本文案   → LLM结构化（当前已有）
├─ 小说/故事   → 四步工作流：规范→分镜→场景表→完整脚本
├─ 网页链接/RSS → web_crawler采集 → 同上流程
└─ 已有视频     → 逆向解构（video-to-prompt）
```

### Layer 2: 分镜引擎（新增/重写）

替换当前的 `director_parser`，核心能力：

```
① LLM场景拆分
   输入: 文案/故事
   输出: 场景列表 (每个场景有时间/地点/氛围)

② 镜头分配
   - 景别: 远景/全景/中景/特写/过肩
   - 运镜: 推/拉/摇/移/跟/升降/环绕
   - 时长: 3-15秒

③ 风格定调
   - 风格锚点: "超写实电影感" / "水墨国风" / "扁平化3D"
   - 色彩方案: 暖调/冷调/高饱和/低饱和
   - 光照方案: 晨光/逆光/霓虹/戏剧光

④ Prompt生成（五要素）
   = [风格] + [主体] + [环境] + [镜头运动] + [光线质感]
   + 负向词 + 权重控制
```

### Layer 3: 素材生产层（多引擎）

```
素材引擎路由:
├─ bailian_kling (主力)  → ¥0.5-1/段, 45s, 已跑通
├─ kling_official        → ¥1/段, 5min, 100积分
├─ jimeng_web (Peekaboo) → ¥0.3/段, 排队, 自动化中
├─ pexels_free           → ¥0/段, 静态, 兜底
├─ wan2.2_digital_human  → 数字人口播
└─ buddy_cloud           → ¥1.8/段, 备用
```

### Layer 4: 合成引擎

```
人声合成: CosyVoice TTS + 字级时间戳
素材处理: Ken Burns (5种随机运镜)
背景音乐: 和弦垫音 / mlx-audiocraft / 即梦BGM
音量避让: duck_bgm (基于字级时间戳)
字幕: ASS 精确字幕
```

### Layer 5: 输出层

```
参数: 1080x1920, 30fps, h264, 8Mbps
格式: mp4
分发: 抖音 / 快手 / 视频号
```

## 三、提示词引擎设计（核心升级）

### 3.1 YAML 脚本格式升级

```yaml
meta:
  project_id: "daoist_002"
  style: "knowledge_lecture"
  global_style_anchor: "水墨国风，工笔山水画质感"  # 新增：全局风格
  global_negative: "畸形、扭曲、面瘫、比例失调"     # 新增：全局负向词
  fps: 24                                          # 新增：帧率
  voice:
    provider: aliyun
    emotion: 专业沉稳
  bgm:
    mood: calm
  output:
    resolution: 1080x1920
    fps: 24

segments:
- id: 1
  text: "上善若水，水善利万物而不争。——《道德经》"
  duration_sec: 10
  # 新增：镜头语言
  camera: "镜头缓慢俯拍，从高空逐渐推进"
  shot_type: "全景"     # 远景/全景/中景/特写
  # 新增：分镜描述（替代旧的 material.search）
  material:
    provider: bailian   # 引擎选择
    prompt_subject: "清澈溪水流过圆石，水滴晶莹"
    prompt_environment: "云雾缭绕的深山幽谷"
    prompt_lighting: "晨雾中的柔光"
  subtitles: true
```

### 3.2 Prompt 组装逻辑

```python
def build_prompt(seg, global_style):
    """五要素+ 权重 + 负向词 组装"""
    prompt = (
        f"({global_style}:1.3), "
        f"({seg['prompt_subject']}:1.5), "
        f"({seg['prompt_environment']}:1.2), "
        f"({seg['camera']}:1.1), "
        f"({seg['prompt_lighting']}:1.0)"
    )
    negative = f"({global_negative}:1.5)"
    return prompt, negative
```

### 3.3 四步分镜工作流

```
输入: "今天我要讲一个关于水的故事。上善若水..."

Step 1: LLM规范整理
  → [场景描述]深山溪谷 [人物动作]无 [对话]旁白

Step 2: 镜头规划
  → 需要 8 个镜头，分布: 全景(2) → 中景(3) → 特写(2) → 全景(1)

Step 3: 场景与角色表
  → 场景1: 深山溪谷，清晨，薄雾
  → 场景2: 水库大坝，午后，阳光强烈

Step 4: 生成完整分镜脚本
  → 镜号 | 景别 | 画面描述 | 旁白 | 场景 | 提示词
```

## 四、多内容类型支持

### 4.1 口播知识类（当前）
- 文案 → TTS → AI素材 → 合成
- 适用：道家金句、知识分享、观点输出

### 4.2 故事叙事类（新增）
- 小说/故事 → 四步分镜 → AI素材 → 合成
- 适用：民间故事、寓言、历史小故事

### 4.3 漫剧动画类（新增）
- 剧本 → 分镜 → 文生图(角色一致) → 图生视频 → 配音
- 适用：短剧、条漫转视频、AI漫剧
- 工具：Kling图生视频 + CosyVoice配音

### 4.4 宣传片类（新增）
- 产品介绍 → 分镜 → 风格化素材 → 合成
- 适用：品牌宣传、产品展示

## 七、AVE 当前状态 vs 目标

```
当前 AVE:
  输入 → 解析 → Pexels → TTS → 合成 → mp4
  │        │       │       │      │
  │ 仅YAML  │ 无分镜 单一素材 │ CosyVoice 无BGM
  
目标 AVE v2.0:
  输入 → 分镜引擎 → 多引擎素材 → TTS→BGM→合成 → mp4
  │        │          │            │
  │ 多类型  │ 四步分镜  │ Kling/即梦  │ 风格统一
  │ 统一入口 │ 五要素prompt │ /Pexels/数字人 │ 全链路控制
```

> **核心理念总结**: 
> 1. **结果推导** — 先想清楚最终画面，再反向拆解指令
> 2. **分镜先行** — 不做文字到视频的直接跳转，先做好分镜
> 3. **风格统一** — 全局风格锚点锁死一致性
> 4. **多引擎** — 根据成本/速度/质量动态选择素材来源
> 5. **持续迭代** — 每次只改5%进行AB测试
