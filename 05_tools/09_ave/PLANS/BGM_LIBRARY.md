## 一、分类体系

### 按情绪 (Mood)

| 情绪 | 标签 | BPM 范围 | 适用场景 |
|:-----|:-----|:--------:|:---------|
| 激昂 | epic, triumphant, powerful | 100-130 | 科技突破、企业里程碑、颁奖 |
| 大气 | cinematic, majestic, grand | 70-90 | 新闻联播、国家成就、纪录片 |
| 紧张 | suspenseful, intense, urgent | 120-150 | 科技竞争、局势分析、倒计时 |
| 温馨 | warm, gentle, cozy | 60-80 | 励志金句、生活记录、情感故事 |
| 励志 | inspiring, uplifting, motivational | 80-110 | 金句合集、个人成长、正能量 |
| 轻松 | happy, cheerful, light | 90-120 | Vlog、日常分享、旅游记录 |
| 科技感 | futuristic, electronic, tech | 110-130 | 芯片、AI、数码产品、演示 |
| 悬疑 | mysterious, dark, ambient | 50-70 | 深度分析、悬疑故事、揭秘 |
| 悲伤 | sad, emotional, melancholic | 55-75 | 感人故事、离别、怀旧 |

### 按场景 (Scene)

| 场景 | 首选情绪 | 备选 | 典型时长 |
|:-----|:--------:|:----:|:--------:|
| 科技新闻/芯片突破 | 激昂 | 科技感、紧张 | 15-45s |
| 励志金句/正能量 | 励志 | 温馨、轻松 | 30-60s |
| 品牌宣传/企业视频 | 大气 | 激昂、科技感 | 30-90s |
| 故事讲述/叙事 | 温馨 | 悬疑、悲伤 | 60-180s |
| 卡点视频/节奏混剪 | 激昂 | 轻松、励志 | 15-30s |
| 片头/片尾 | 大气 | 激昂、励志 | 3-8s |
| 科普/知识分享 | 轻松 | 温馨、科技感 | 30-120s |

## 三、AI 生成参考 (mlx-audiocraft Prompt 模板)

以下 prompt 与上述曲库风格对应, 可用于 `--use-mlx` 模式生成类似风格的 BGM:

```bash
# 激昂 (对标 Heroes Today)
python main.py bgm --mood epic --duration 60 --use-mlx
# → prompt: epic orchestral, brass and strings, powerful drums, 120 BPM

# 大气 (对标 Inspire)
python main.py bgm --mood inspiring --duration 60 --use-mlx  
# → prompt: uplifting cinematic, building strings, triumphant, 85 BPM

# 励志
python main.py bgm --mood happy --duration 60 --use-mlx
# → prompt: bright ukulele, cheerful melody, acoustic guitar, 90 BPM

# 科技感 (使用 custom prompt)
HF_ENDPOINT=https://hf-mirror.com python main.py bgm --mood normal --duration 60 --use-mlx
# → 用自定义 prompt 覆盖: electronic futuristic, synth pads, 120 BPM
```

### Prompt 优化技巧

| 效果 | 关键词 |
|:-----|:-------|
| 更激昂 | `epic, triumphant, powerful crescendo, building tension` |
| 更柔和 | `soft, gentle, warm, relaxing, smooth` |
| 更快节奏 | `driving beat, fast tempo, energetic` |
| 更有电影感 | `cinematic, orchestral, dramatic swells` |
| 更科技感 | `electronic, synth, futuristic, digital` |
| 更真实乐器 | `acoustic, piano, strings, live instruments` |
| 不要打击乐 | `no percussion, no drums` |
| 纯背景 | `ambient, background, subtle, pad` |

## 五、使用方式

### 人工选曲
```bash
# 查看此文档 → 按情绪/场景定位 → 按链接下载 → 放入对应目录
python bgm_generator/bgm_download.py list
```

### AI 生成 (替代选曲)
```bash
# 直接生成对应情绪的 BGM (如激昂类型)
HF_ENDPOINT=https://hf-mirror.com python main.py bgm --mood epic --duration 60 --use-mlx

# 效果不满意可以加自定义 prompt
python -c "
from bgm_generator.suno import generate_bgm
generate_bgm(
    mood='custom',
    duration=60,
    output='/tmp/custom_bgm.wav',
    use_mlx=True,
)
# 内部会使用自定义 mood 的 prompt
"
```

### 与视频工厂集成
```bash
# 口播 + BGM (选 AI 生成或已有曲目)
python main.py video-factory --strategy 口播 --script script.yaml --bgm /path/to/bgm.wav --duck

# 卡点 + BGM (自动节拍检测)
python main.py video-factory --strategy 卡点 --bgm /path/to/bgm.wav --search "nature"
```
