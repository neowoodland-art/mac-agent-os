| **PixVerse V6** | ¥0.48/s | 海外用户超千万 | ✅ API | 低 |

### 3.2 AVE 漫剧集成方案

```
文案 → LLM分镜 → 角色一致性控制 → Kling/通义万相逐帧生成 → 
FFmpeg合成 → 配音(CosyVoice) → BGM → final.mp4
```

关键点：**角色一致性** 是 AI 漫剧的难点，可灵和通义万相支持图生视频，可以用同一张角色图作为参考。

## 四、战略架构建议

### 4.1 三层管线 (Tiered Pipeline)

```
                     用户文案
                         │
              [01_director_parser]  ← oMLX 本地解析
                         │
         ┌───────────────┼───────────────┐
         ▼               ▼               ▼
   Tier 1: 免费      Tier 2: 批量     Tier 3: 高品质
   ──────────       ────────────     ─────────────
   Kling 50次/月     Kling API $0.20  通义万相1080p
   通义万相50s       即梦网页版会员     Runway 4K
   Dreamina积分      buddy-cloud      Sora 2
         │               │               │
         └───────────────┼───────────────┘
                         ▼
               [material_producer]
               AI素材 → 下载 → 缓存
                         │
               [composer] Ken Burns + 字幕
                         │
                    final.mp4
```

1. **短期**: 即梦网页版 Peekaboo 自动化继续搞完，成本最低
2. **中期**: 接入 **Kling API** — 国际性价比之王，每月50次免费额度
