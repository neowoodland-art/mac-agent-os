# AVE 视频工厂 — 策略体系 v1.0

> 最后更新: 2026-05-09 | 版本: v1.0

## 概述

将视频生产按策略分类, 每种策略有独立的输入/处理/输出管线。
生成时只需选择策略 + 提供内容素材, 系统自动路由到对应管线。

---

## 策略一览

### ① 口播策略 (当前可用 ✅)

| 项目 | 内容 |
|:-----|------|
| **输入** | 文案脚本 (YAML/TXT) |
| **核心流程** | 文案→CosyVoice TTS→Pexels素材搜索→mlx-audiocraft BGM→BGM避让→锚点画面切换→精确字幕→(可选)数字人片头片尾 |
| **CLI** | `python main.py generate --script xxx.yaml --bgm xxx.wav --duck --anchor-transitions` |
| **适用场景** | 知识分享、励志金句、故事讲述、教程讲解 |
| **输出** | 40-60s 竖屏视频, 1080p |
| **依赖** | 阿里云百炼(CosyVoice), Pexels, 火山引擎(OmniHuman 可选) |

### ② 卡点策略 (待开发 🔧)

| 项目 | 内容 |
|:-----|------|
| **输入** | BGM + 图片/视频素材列表 |
| **核心流程** | BGM→librosa节拍检测→按4拍/8拍分组→素材分配→拍点切换→xfade过渡→文字叠加 |
| **CLI** | `python main.py beat-sync --bgm xxx.wav --images img1.jpg img2.jpg` |
| **适用场景** | 卡点视频、节奏混剪、照片 Slideshow |
| **关键能力** | librosa beat_track 检测拍点; FFmpeg xfade ≤8段过渡 |
| **已知限制** | xfade 链 >10段 FFmpeg 崩溃, 需分组 ≤8段 |

### ③ 数字人策略 (部分可用 🔧)

| 子策略 | 能力 | API | 状态 |
|:-------|:-----|:----|:----:|
| **OmniHuman** | 头像图片 + 音频 → 对口型视频 | 火山引擎 CV API | ✅ 可用 |
| **DreamActor M1** | 照片 + 参考视频 → 动作模仿 | 火山引擎/即梦 API | 🔧 待接入 |
| **动作模仿流程** | 找参考视频 → 上传照片 → 提交 DreamActor → 下载结果 | — | 🔧 |

### ④ 模板策略 (调研中 🔍)

| 项目 | 内容 |
|:-----|------|
| **目标** | 程序化生成剪映草稿, 利用剪映模板/渲染能力 |
| **候选工具** | • pyJianYingDraft (Python 生成剪映草稿)<br>• cutcli (剪映草稿 CLI)<br>• CapCutAPI (完整剪映编程接口) |
| **思路** | AVE 生成草稿文件 → 剪映打开/CLI渲染 → 得到最终视频 |
| **优势** | 可复用剪映的丰富模板和特效 |
| **风险** | 剪映版本更新可能导致草稿格式变更 |
