# 抖音平台插件

## 能力

| 接口 | 状态 | 说明 |
|------|:----:|------|
| login | ✅ | 打开浏览器扫码登录 |
| collect | ✅ | 采集抖音主页信息 |
| status | ✅ | 检查登录状态 |
| publish | 📋 | 计划中 (集成 social-auto-upload) |
| nurture | ✅ | 执行养号蓝图 |

## 用法

```bash
mc douyin collect --account 手机号
mc douyin login --account 手机号
mc douyin status --account 手机号
```
