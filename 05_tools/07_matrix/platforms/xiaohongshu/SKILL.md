# 小红书平台插件

## 能力

| 接口 | 状态 | 说明 |
|------|:----:|------|
| login | ✅ | 打开浏览器扫码登录 |
| collect | ✅ | 采集小红书主页信息 |
| status | ✅ | 检查登录状态 |
| publish | 📋 | 计划中 (集成 social-auto-upload) |

## 用法

```bash
mc xiaohongshu collect --account 手机号
mc xiaohongshu login --account 手机号
mc xiaohongshu status --account 手机号
```
