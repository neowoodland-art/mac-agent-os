# OpenCLI — 网站命令行化工具 安装与集成指南

> 版本: v1.0 / 最后更新: 2026-05-29
> 适用: AgentOS 所有节点

---

## 背景

OpenCLI (github.com/jackwener/OpenCLI) 能将**任何网站转化为 CLI 接口**，通过 Chrome 扩展 + CDP 协议操控网页。与 Camoufox 互为补充：
- **Camoufox**: 反检测浏览器 → 养号/登录态操作
- **OpenCLI**: 复用已登录 Chrome → 内容采集/查询

---

## 一、一键安装脚本

```bash
#!/bin/bash
# install_opencli.sh — 自动安装 OpenCLI + Chrome 扩展

set -e

echo "=== 1. 安装/升级 OpenCLI CLI ==="
npm install -g @jackwener/opencli

echo "=== 2. 下载 Chrome 扩展 ==="
EXT_DIR="$HOME/.opencli/extension"
mkdir -p "$EXT_DIR"
curl -sL "https://github.com/jackwener/OpenCLI/releases/download/v1.8.0/opencli-extension-v1.0.15.zip" \
  -o /tmp/opencli-ext.zip
unzip -qo /tmp/opencli-ext.zip -d "$EXT_DIR"
rm /tmp/opencli-ext.zip

echo "=== 3. 创建 Chrome 启动指令（含扩展） ==="
# 写入启动脚本
cat > "$HOME/.opencli/start_chrome_with_opencli.sh" << 'EOF'
#!/bin/bash
pkill -f "Google Chrome" 2>/dev/null
sleep 1
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome \
  --load-extension="$HOME/.opencli/extension" \
  --remote-debugging-port=0 &
echo "Chrome 已启动（OpenCLI 扩展已加载）"
EOF
chmod +x "$HOME/.opencli/start_chrome_with_opencli.sh"

echo "=== 4. 启动 Chrome + 扩展 ==="
bash "$HOME/.opencli/start_chrome_with_opencli.sh"
sleep 3

echo "=== 5. 验证 ==="
opencli doctor

echo ""
echo "✅ OpenCLI 安装完成！"
echo "下次开机后运行: opencli daemon start"
echo "然后用: bash ~/.opencli/start_chrome_with_opencli.sh"
```

## 二、日常使用

### 2.1 Chrome 扩展机制

OpenCLI 通过 Chrome 扩展 + 本地守护进程（端口 19825）通信：
- `opencli daemon start` → 启动守护进程
- Chrome 扩展自动连接守护进程
- 所有网站操作通过**已登录的 Chrome Cookie** 执行，零额外登录

### 2.2 常用命令

```bash
# 内容采集
opencli xiaohongshu search "AI视频" --limit 10 -f json
opencli bilibili hot --limit 20 -f json
opencli zhihu hot -f json
opencli douyin search "AI绘画" --limit 10

# 浏览器操作（AI Agent 驱动）
opencli browser "打开小红书通知页面"
opencli browser "搜索抖音上的AI视频教程"

# 输出格式
-f json    # JSON结构化输出（AI Agent 友好）
-f csv     # CSV 表格
-f yaml    # YAML 格式
-f md      # Markdown
```

### 2.3 集成到 AgentOS

```bash
# 将 OpenCLI 技能安装到 AI Agent
npx skills add jackwener/opencli

# 安装特定技能
npx skills add jackwener/opencli --skill opencli-browser
npx skills add jackwener/opencli --skill opencli-adapter-author
```

## 三、多机部署方案

### 3.1 每台机器独立安装

各机器按上述脚本走一遍即可。需要：
1. Node.js >= 20（AgentOS 已预装）
2. Google Chrome（各机器已预装）
3. 网络可访问 GitHub（扩展下载）

### 3.2 共享配置

OpenCLI 配置保存在 `~/.opencli/` 目录：
- `clis/` → 已安装的适配器
- `extension/` → Chrome 扩展文件
- `node_modules/` → 依赖

此目录不跨机同步，每台机器独立安装。

### 3.3 注意

- 每台机器的 Chrome **登录态独立**（Google 账号/Douyin/Cookie 互不共享）
- OpenCLI 会用**各自 Chrome 已登录的 Cookie** 操作网站

## 四、常见问题

| 问题 | 解决 |
|------|------|
| `[MISSING] Extension: not connected` | Chrome 未用 `--load-extension` 启动 |
| 扩展已装但连不上 | `opencli daemon restart` + 重启 Chrome |
| 命令返回空数据 | 检查 Chrome 是否已登录目标网站 |
| 守护进程端口冲突 | `OPENCLI_DAEMON_PORT=19826 opencli daemon start` |

## 五、与 AgentOS 现有工具的对比

| 工具 | 场景 | 优势 | 劣势 |
|------|------|------|------|
| **Camoufox** | 养号、登录态操作 | 反检测、指纹隔离 | 启动慢、Firefox |
| **OpenCLI** | 内容采集、查询 | 复用已登录Chrome、极快 | 无反检测、不能养号 |
| **agent-browser** | 简单页面操作 | WorkBuddy内置 | 能力有限 |
| **WebFetch** | 静态页面抓取 | 简单直接 | 无法交互 |
