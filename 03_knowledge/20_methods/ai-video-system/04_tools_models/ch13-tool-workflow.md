# Ch13: 工具实操与工作流搭建

> 结果导向：从"想要的成果"选择工具+搭建工作流

---

## 一、四大核心工具详解

### Runway Gen-3 Alpha
**定位**：电影级画质、精细控制，专业制作首选

**操作流程**：
1. 准备高质量静态图（建议1080p以上，最好4K）
2. 上传图片至平台（支持JPG/PNG）
3. 编写提示词描述期望的动态效果
4. 调整 Camera Motion 参数和 Motion Bucket
5. 生成预览（耗时2-5分钟）
6. 不满意可调整参数重试

**提示词结构**：
```
主体描述 + 动作行为 + 环境背景 + 镜头语言 + 光影效果 + 风格参数
```
示例：`A golden retriever running through a sunlit meadow, slow motion, cinematic camera tracking shot, warm golden hour lighting`

**参数**：
- Motion Bucket：0-10（控制运动强度）
- Camera Motion：Dolly In/Out、Tracking Shot、Orbit、Bird's Eye
- 时长上限：16秒
- 分辨率：最高4K

---

### Kling 可灵
**定位**：中文理解最佳、性价比高

**操作流程**：
1. 准备1080p以上静态图
2. 上传图片（支持JPG/PNG）
3. 用自然语言描述动态效果
4. 选择运动模式
5. 生成预览（耗时1-3分钟）

**提示词**：直接用中文写，自然语言描述
**参数**：通过界面选择运动强度，时长上限10秒（可扩展）
**价格**：免费/付费（付费可商用）

---

### Pika 2.0
**定位**：简单易用、区域编辑，适合入门

**操作流程**：
1. 准备720p以上静态图
2. 上传图片
3. 编写提示词（支持 `--no` 负面参数）
4. 选择区域动画（指定画面某部分动）
5. 应用 Pikaffects 特效
6. 生成预览（耗时1-2分钟）

**特色**：
- 支持 `--no` 参数排除不想要的内容
- Pikaffects 特效一键应用
- 区域动画可指定画面局部运动
- 分辨率最高720p

---

### Sora
**定位**：物理模拟最强、支持长视频

**流程**：纯自然语言描述 → 生成最长60秒视频
**参数控制**：全部通过文字描述，无独立参数面板
**优势**：物理模拟最强（物体运动、碰撞、流体真实）
**限制**：仅ChatGPT Plus可用（$20/月）

## 三、结果导向工作流

### 快速出片（30分钟内）
```
Pika(快速生成) → 剪映(剪辑+配乐) → 发布
适合：日常短视频、快速验证创意
```

### 工业级制作（3小时+）
```
Midjourney(生图) → Runway(视频化+运动控制) → 
Au(声音设计) → Premiere(精剪) → 输出
适合：商业TVC、品牌广告
```

### 中文短视频（1小时内）
```
Kling(中文提示词→视频) → 剪映(配乐+字幕) → 发布
适合：抖音/B站中文内容
```

### 长叙事（2小时+）
```
分段生成(Sora长镜头) → 剪辑拼接 → 声音设计 → 输出
适合：短片/叙事类内容
```

### 跨工具联动

```
Gen-2生成高精度画面 → Runway动态扩展 → Au声音设计 → 工业级短片
推荐组合：
- 商业广告：Gen-2(画面) + Au(声音)
- 动漫番剧：Pika(多镜头连贯) + 配音平台(对白)  
- 电影短片：Kling 3.0(素材) + Runway(后期)
```

---

## 四、通用最佳实践（所有工具适用）

1. **图片先行**：先用AI图像工具生成满意画面，再转视频
2. **分段生成**：长视频每段5-10秒，后剪辑拼接
3. **迭代优化**：多次生成逐步改进
4. **后期处理**：AI生成后加音乐、文字、转场
5. **建立提示词库**：记录成功提示词和参数
