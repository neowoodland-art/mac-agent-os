# Ch14: 从"创意"到"AI友好型脚本"的转化

> 结果导向：从"叙事目标"反推脚本结构+分镜+提示词

---

## 一、四步工作流：小说→分镜脚本

### 核心原理
采用"思维链"策略，将复杂任务拆解为多个简单子任务。

### 四步流程

**第一步：规范化整理内容**
```
将原文交给AI，要求输出规范格式：
明确标识出[场景描述]、[人物动作]、[对话]
让AI预先"阅读"并理解故事
```

**第二步：预估镜头数与结构分布**
```
让AI分析文本进行宏观规划：
- 需要多少镜头？
- 镜头在关键情节中的分布？
- 建立视觉节奏感
```

**第三步：搭建核心场景与角色表**
```
为每个场景和关键角色生成视觉描述：
- 场景1：咸亨酒店大堂，午后，光线昏暗，柜台有酒坛
- 角色A：孔乙己，瘦弱，长衫破旧
目的：确保视觉一致性，节省后续token
```

**第四步：整合生成分镜脚本**
```
结合前三步成果，生成完整分镜：
镜头编号 | 景别 | 画面描述 | 对话 | 场景 | 角色
```

**效果对比**（以《孔乙己》为例）：
- 直接转换：仅12个镜头
- 四步工作流：59个分镜头 ✅ 完整还原剧情

### 提示词模板

```
步骤1："请将以下小说内容重新整理，明确标识出[场景描述]、[人物动作]和[对话]"
步骤2："分析并告诉我需要多少个镜头？列出在关键情节中的分布"
步骤3："创建场景表和角色表，为每个场景/角色生成视觉描述"
步骤4："结合前三步成果，创建完整分镜脚本，以表格形式输出"
```

## 二、场景控制技术

### 先建库，再使用

不要在每个镜头中重复描述场景，先建全局场景表：
```
场景1：咸亨酒店大堂，午后，光线昏暗，柜台上有酒坛
场景2：街道，傍晚，下着小雨，石板路湿润
```

后续每个镜头只需引用"场景1"即可。

### 场景描述要素

| 要素 | 描述内容 |
|------|---------|
| 环境 | 室内/室外，具体地点 |
| 时间 | 清晨/午后/夜晚 |
| 光线氛围 | 明亮/昏暗/阴森/温暖 |
| 关键道具 | 酒坛/柜台/书桌 |
| 文化符号 | 特定时代的建筑/服饰 |

### 场景互动

| 场景类型 | 细节锚点 |
|---------|---------|
| 市场 | 商贩叫卖，人群拥挤，摊位细节(糖葫芦/布幡) |
| 太空舱 | 警报灯闪烁，仪器面板发光，失重漂浮物 |
| 恐怖屋 | 昏暗，角落蛛网，光影斑驳 |
| 咖啡厅 | 暖光，蒸汽升腾，背景交谈声 |

## 三、AI友好型脚本格式

### 模块化结构

```
0-3秒：[景别] [画面描述] [镜头运动] | 光影：[参数] | 音频：[参数]
3-7秒：[景别] [画面描述] [镜头运动] | 光影：[参数] | 音频：[参数]
```

### 完整示例

```
小说："他在雨夜的巷子里奔跑，心跳如鼓"
→ 
0-5秒：中景跟拍，男性在雨夜巷奔跑，脚步急促，镜头轻微晃动
   光影：雨夜冷光，地面水洼反光
   音频：雨声(密集) + 心跳声(低频，渐强)
```
