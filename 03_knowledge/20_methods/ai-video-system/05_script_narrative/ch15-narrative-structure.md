# Ch15: 叙事结构与AI叙事能力的结合

> 核心：扬长避短——AI擅长视觉化情绪，弱化复杂对白逻辑

---

## 常见叙事结构

| 结构类型 | AI适配度 | 说明 |
|---------|---------|------|
| 线性叙事 | ⭐⭐⭐⭐⭐ | 时间顺序，AI最容易理解 |
| 非线性叙事 | ⭐⭐⭐ | 需要明确的时间标记 |
| 多线叙事 | ⭐⭐ | 需要分线标记+交叉点 |
| 倒叙/插叙 | ⭐⭐⭐ | 需要明确的时间锚点 |

## AI叙事优势与局限

### AI擅长
- 视觉化情绪（光影+微表情+场景）
- 高密度画面叙事（每一秒承载大量信息）
- 风格化渲染（电影感/动漫感）

### AI不擅长
- 复杂对白逻辑（容易混淆人物关系）
- 细微情感递进（缺少层次感）
- 长时间连贯性（超过30秒容易崩）

### 策略：扬长避短

```
用动作/光影/场景替代对白推进剧情
用分段生成解决长叙事
用视觉符号替代文字说明
```

## 短剧分镜7大要素

1. 景别（远全中近特）
2. 视角（平俯仰倾）
3. 构图（三分法/对称/不对称）
4. 光影（情绪映射）
5. 运动（镜头+主体）
6. 音频（对白+环境+配乐）
7. 转场（硬切/溶解/首尾帧）
