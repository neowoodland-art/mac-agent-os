# 结果推导创作模板

> 用法：每次创作新视频前填写此模板，从"想要的成果"反推完整指令

---

## 1. 成果定义

```
目标视频类型: [电影/动漫/广告/短视频/实验片...]
核心情绪: [紧张/温馨/史诗/悬疑/科幻...]
目标时长: [15s/30s/1min...]
发布平台: [抖音/B站/YouTube...]
参考风格: [赛博朋克/赛璐璐动画/胶片质感/...]
```

## 2. 反推：场景

```
场景类型: [室内/室外/城市/自然/太空...]
时间: [白天/夜晚/黄昏/黎明]
光影: [冷光/暖光/侧光/背光/高对比/柔焦]
氛围: [明亮/昏暗/烟雾/雨/雪/霓虹]
```

## 3. 反推：人物

```
人物形象: [年龄/性别/服饰/发型/体态]
核心表情: [喜悦/悲伤/愤怒/恐惧/惊讶/疑惑]
微表情参数: [眼神/眉毛/嘴角/颈部/手部]
动作细节: [姿势/动作/速度/节奏]
```

## 4. 反推：分镜与运镜

```
景别序列: [远景→中景→特写→...]
运镜方式: [推进/拉远/跟随/环绕/手持/固定]
节奏: [快/中/慢]
转场: [硬切/溶解/推拉/首尾帧]
```

## 5. 反推：音频

```
背景音乐情绪: [紧张/温馨/史诗/悬疑...]
音乐风格: [管弦乐/电子/摇滚/民谣...]
BPM: [60/90/120...]
音量: [30dB/40dB/50dB...]
环境音: [风声/雨声/城市/森林/机械音]
对白: [有/无] 音色: [低沉/清脆/沙哑]
```

## 6. 反推：工具选型

```
首选工具: [Runway/Pika/Gen-2/SVD/可灵/即梦]
理由: [快速验证/风格一致/精度高/定制化]
辅助工具: [Midjourney/豆包/DALL-E/Deepseek]
工作流: [描述完整的工具链]
```

## 7. 反推：提示词

```
最终提示词:

[在此填写完整的提示词]
```

---

## 示例：悬疑短片

```
目标: 15秒悬疑短片 → 抖音发布
情绪: 紧张、不安、未知恐惧
场景: 废弃医院走廊，午夜，冷色荧光灯闪烁
人物: 男性，30岁，面容焦虑，眼睛不断扫视四周
分镜: 远景建环境→中景跟拍→特写面部(眼神闪烁)
运镜: 手持晃动，慢推进
音频: 环境音(电流嗡鸣)bgm(低音弦乐渐强)
工具: 可灵3.0（优质光影）+ 专业音频设计
```
