# Ch3: 基础定调参数

> 结果导向：从"想要的画质/质感/稳定性"反推参数组合

---

## 一、分辨率选型

### 按场景推荐

| 场景 | 推荐分辨率 | 理由 |
|------|-----------|------|
| 创作初期测试 | 768p 或更低 | 生成稳定，显存低，快速验证构图和动作 |
| 手机短视频(抖音/B站) | 1080p (2K) | 小屏幕难分辨更高清，避免浪费算力 |
| 商业大屏/高端展示 | 4K | 基准线，确保细节质感 |
| 专业电影/广告 | 8K+ | 分块生成后缝合（需同Seed+锁定风格参数） |
| VR全景(360°) | 等距柱状投影 | 或多视角生成后合成 |

### 显存/算力平衡方案

1. **高低配工作流**：低清(768p)生成 → 超分算法放大
2. **启用显存优化**：检查工具是否支持"时间切片"或"梯度检查点"
3. **利用云算力**：单次高负荷任务租用云渲染

## 二、帧率选型

### 帧率速查表

| 应用场景 | 推荐帧率 | 说明 |
|---------|---------|------|
| 电影感(叙事短片) | **24fps** | 轻微动态模糊，绑定电影质感 |
| 流畅感(游戏/运动) | **30fps / 60fps** | 观感清晰流畅 |
| 极致慢动作 | **120fps / 240fps** | 用插帧实现：先30-60fps生成，再用AI插帧 |
| 风格化动画 | **12fps** | 抽帧效果，漂移本身可成为艺术风格 |
| 动态帧率 | 分段生成 | 对话24fps + 动作60fps，后期合成 |

### 艺术化搭配

| 搭配 | 效果 |
|------|------|
| 高帧率 + 轻微运动模糊 | 清晰顺滑但真实 |
| 低帧率(24fps) + 较强运动模糊 | 强化电影梦幻感和动态张力 |
| 高速运动时调高运动模糊 | 掩盖AI在细节连贯性上的不足 |

**小窍门**：用高帧率生成，后期抽帧降到24fps，比直接生成24fps得到更自然的运动模糊。

## 三、画面比例

| 比例 | 适用平台 | 说明 |
|------|---------|------|
| **9:16** | 抖音/快手/小红书/视频号 | 手机全屏，竖屏短视频黄金比例 |
| **16:9** | B站/YouTube/电视 | 横屏标准比例，通用性强 |
| **1:1** | 小红书/Instagram | 正方形，图文平台视频 |
| **2.35:1** | 电影宽银幕 | 电影感最强，上下黑边 |
| **4:3** | 复古/纪录片风格 | 老电视/胶片比例 |

## 四、参数协同：性能三角

```
质量 ← → 速度
   ↓   ↑
   稳定性
```

三个维度相互制约，需要根据场景做取舍。

### 场景化参数模板

| 视频类型 | 帧率 | 分辨率 | 一致性 | 优先维度 |
|---------|------|--------|--------|---------|
| **叙事短片** | 24fps | 2K起 | 高 | 质量和稳定性 |
| **产品广告** | 60fps | 4K | 极高 | 清晰和流畅 |
| **手机短视频** | 30fps | 1080p | 中 | 速度和效率 |
| **风格化动画** | 12fps | 灵活 | 灵活 | 艺术自由度 |
| **电影感创作** | 24fps | 4K | 高 | 电影质感 |
| **测试/草稿** | 24fps | 768p | 低 | 快速迭代 |

## 五、质感参数映射（风格→参数）

| 目标质感 | 参数组合 |
|---------|---------|
| **电影级** | ARRI Alexa + Kodak 5219 + 24fps + 2.35:1 |
| **动漫赛璐璐** | 赛璐璐质感 + 手绘笔触 + 12-24fps |
| **赛博朋克** | 霓虹色调 + 高对比度 + 冷色温 + 体积雾 |
| **纪录片** | 自然光 + 真实色彩还原 + 16:9 |
| **胶片复古** | 胶片颗粒 + 暖色调 + 4:3比例 |
| **科幻史诗** | 冷色调 + 宏大光影 + 2.35:1 |

### 新手优先顺序

```
帧率 → 分辨率 → 一致性
1. 确保基础流畅度（设定帧率）
2. 根据平台确定分辨率
3. 调整一致性减少闪烁
```

## 六、运动参数

### Motion Bucket（Runway等工具）

| 数值 | 效果 | 适用场景 |
|------|------|---------|
| 0-3 | 轻柔缓慢 | 对话场景、特写 |
| 4-6 | 中等 | 一般运动、走路 |
| 7-8 | 快速 | 跑步、追逐 |
| 9-10 | 剧烈 | 高速动作、混乱 |

### Camera Motion 参数

| 运镜 | 效果 | 使用场景 |
|------|------|---------|
| Dolly In | 镜头推进 | 引人入胜、强调 |
| Dolly Out | 镜头拉远 | 揭示全貌、失落 |
| Tracking Shot | 跟拍 | 动作跟随 |
| Orbit | 环绕 | 展示主体 |
| Bird's Eye | 俯拍 | 宏大场景 |

## 九、最佳实践总结

### 建立参数预设库

创建三档预设快速切换：

| 预设 | 分辨率 | 帧率 | 用途 |
|------|--------|------|------|
| 探索-快速 | 768p | 24fps | 构图和动作测试 |
| 制作-标准 | 1080p | 30fps | 日常内容产出 |
| 精修-高质量 | 4K | 24fps | 商业/精品 |

### 操作顺序

1. 确定发布平台 → 选择比例和分辨率
2. 确定内容类型 → 选择帧率
3. 调整运动参数 → 匹配场景节奏
4. 小样测试 → 调整一致性
5. 批量生成 → 后期剪辑统一调色
