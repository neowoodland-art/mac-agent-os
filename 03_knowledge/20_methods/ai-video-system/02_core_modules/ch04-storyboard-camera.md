# Ch4: 分镜时序与运镜

> 结果导向：从"想要的叙事效果"反推分镜与运镜

---

## 一、结果推导

```
紧张追逐戏 → 分镜节奏快 + 手持运镜 + 快速切换
抒情慢镜头 → 固定机位 + 长镜头 + 缓慢推进
悬疑氛围 → 缓慢平移 + 特写堆叠 + 延迟剪辑
史诗场面 → 航拍俯视 + 大远景 + 缓慢拉升
```

## 二、多镜头切换的一致性方案

### 核心问题

AI 视频在不同镜头之间切换时，角色外貌、场景风格、光照条件容易发生"漂移"。解决思路是**建立锚点 + 控制变量 + 后期统一**。

### 方案一：提示词锚定法（零成本）

每个镜头的提示词中复制粘贴相同角色外貌描述，用文字锚点约束模型：

``` 
"与场景1相同的角色：30岁东亚女性，齐肩直黑发，棕色眼睛，
穿着红色皮夹克配白色圆领T恤，深蓝色修身牛仔裤，白色运动鞋"
```

**关键规则**：
- 描述越具体越好（颜色/材质/年龄/体型）
- 跨镜头复制相同文字（重复=一致性）
- 添加统一风格锚点："电影级，35mm胶片拍摄，蓝绿和橙色调色"

### 方案二：参考图锚定法（最可靠）

使用图生视频（I2V）方式：
1. 生成高质量角色参考图作为第一帧
2. 每个新镜头都重新选择一张合适的参考图
3. 提示词只描述运动，不再描述外貌（模型已从参考图看到）

**最佳工具**：Seedance 2.0（身份锁定系统）、可灵3.0（分镜模式6个机位自动一致）

### 方案三：分段锚定法（长视频）

```
每5-10秒生成一段 → 手动选最佳帧作为关键帧 →
下一段以关键帧为参考继续生成 → 利用"一致性重注入"
```

### 方案四：后期统一

- 并排对比所有场景
- 漂移严重的以锚定场景为参考重生成
- 统一调色：剪映/达芬奇应用统一LUT掩盖细微差异

### 实战流程总结

```
锚定场景(首帧完美镜头) → 
提示词锚定(关键特征跨镜头复制) → 
参考图锚定(I2V锁定角色/场景) → 
分段生成(每5-10秒校准) → 
后期统一调色 → 审查修正
```

## 三、十大镜头运动

| # | 运动类型 | 效果 | 情绪 |
|---|---------|------|------|
| 1 | Dolly In（推进） | 靠近主体，增加紧张感 | 紧张/强调 |
| 2 | Dolly Out（拉远） | 后退展现全貌 | 失落/揭示 |
| 3 | Tracking Shot（跟拍） | 跟随主体移动 | 代入感 |
| 4 | Orbit（环绕） | 围绕主体旋转 | 展示/气势 |
| 5 | Crane（升降） | 从低到高或高到低 | 开场/结尾 |
| 6 | Slow Motion（慢动作） | 放慢动作放大张力 | 情绪高潮 |
| 7 | Handheld（手持） | 轻微晃动，真实感 | 紧张/纪实 |
| 8 | POV（第一人称） | 主观视角 | 沉浸感 |
| 9 | Dutch Angle（倾斜） | 画面倾斜 | 不安/失衡 |
| 10 | Rack Focus（焦点切换） | 焦�.从前景切换到背景 | 引导注意 |

## 四、景别→情绪曲线（来自李导V4）

```
远景→近景→远景：励志氛围
中景→近景→特写：紧张氛围
远景→特写：戏剧性（震惊/发现/转折）
特写→远景：情绪释放/留白
```

## 五、分镜节奏控制

| 节奏 | 镜头时长 | 适用场景 |
|------|---------|---------|
| 快节奏 | 1-3秒/镜头 | 动作/追逐/紧张 |
| 中节奏 | 3-5秒/镜头 | 对话/叙述 |
| 慢节奏 | 5-10秒/镜头 | 抒情/氛围/史诗 |

## 六、Seedance长镜头转场技巧（来自李导V9）

- **首尾帧模式**：前一段尾帧作下一段首帧参考 → 无缝转场
- **提示词结构**：主体+动作+场景+细节+运镜+风格+转场
- **场景切换**：用尾帧过渡法实现打斗→对话的流畅切换
