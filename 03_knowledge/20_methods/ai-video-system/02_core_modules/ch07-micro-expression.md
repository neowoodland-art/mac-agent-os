## 第一部分：角色一致性

### 一、4种核心方法（由简到繁）

| 方法 | 操作 | 适用场景 | 关键注意 |
|------|------|---------|---------|
| **起始帧（I2V）** | 上传1张角色图作为第一帧 | 快速单场景，5-10秒片段 | 提示词偏差过大会漂移 |
| **关键帧插值** | 上传起点和终点两张图，中间自动过渡 | 已知起止位置的运动 | 需要每镜头2张图 |
| **重生成+修改** | 先生成基础视频，再修改换背景/调光照 | A/B测试多个版本 | 3-4次后漂移累积 |
| **分层合成** | 绿幕生成角色动画+单独背景，后期合成 | 专业制作，环境变化大的复杂场景 | 需基础合成技能 |

### 三、实操6步流程

1. **定义角色**：准备3-5张角色图（正面/四分之三侧面/侧面），≥1024x1024，光线清晰
2. **创建风格指南**：用文字记录发色/发型/瞳色/服装/辨识标记
3. **规划镜头**：列出每个场景的机位角度/动作/场景设定/氛围
4. **生成锚定场景**：从最重要的场景开始（特写或主视觉），生成完美镜头作为参照
5. **生成其余场景**：以锚定场景为参考，每个提示词必须包含角色参考图和风格指南
6. **审查与重生成**：并排对比所有场景，漂移的以锚定场景为参考重生成

### 四、5个核心操作技巧

1. **参考图技巧**：至少3-5张不同角度，≥1024x1024，光线一致，纯色背景，服装统一
2. **给角色命名**：所有提示词使用统一名字，在注意力机制中创建身份锚点
3. **强制复述**：每个场景重复关键特征（"黑发女性，蓝色夹克"），重复就是一致性
4. **明确指令**：告诉模型保留什么——"与场景1相同的角色，相同服装，相同发型"
5. **控制变量**：场景之间一次只改一个元素

### 五、实战工作流（多镜头切换）

```
【准备】创建角色设定图(4-6张不同角度) →
【核心】I2V生成关键镜头(特写/中景用参考图) →
【辅助】提示词锚定生成辅助镜头(全景/过渡用文字锚点) →
【修补】换脸修复明显偏差的面部片段 →
【统一】导入剪辑软件统一调色掩盖细微差异 →
【审查】从头检查面部/服装/发型/肤色连贯性
```

### 六、常见错误

| ❌ 错误 | ✅ 正确做法 |
|---------|-----------|
| 一次性改太多变量 | 新场景+新角度+新光照+新动作=漂移，一次只改一个 |
| 使用低质量参考图 | ≥1024x1024，光线一致 |
| 提示词忽略服装 | 服装是重要身份锚点，必须指定 |
| 没有锚定场景 | 先生成最好的角色镜头作为全局参考 |
| 指望一个模型搞定所有 | 特写和远景可能需要不同模型 |

### 情绪→微表情映射

| 情绪 | 微表情参数 | 动作细节 | 提示词示例 |
|------|-----------|---------|-----------|
| 喜悦 | 嘴角上扬，眼角出现笑纹，眼神发光 | 身体微倾，手势开放 | `slight smile, corners of mouth lifting, eyes sparkling` |
| 悲伤 | 嘴角下垂，眉头微皱（眉心出现竖纹），眼睛无神 | 低头，肩膀下垂 | `slight frown, downturned mouth, eyes unfocused` |
| 愤怒 | 眉头紧锁（朝鼻梁挤压），嘴唇紧抿，鼻孔微张 | 手指握拳，身体前倾 | `furrowed brows, clenched jaw, glaring eyes` |
| 恐惧 | 眼睛睁大（瞳孔放大），眉毛上抬并朝中间靠拢，嘴唇微张 | 身体后缩，手部颤抖 | `wide eyes, raised eyebrows, trembling lips` |
| 惊讶 | 眉毛大幅度上抬，眼睛圆睁，嘴巴张开呈O型 | 身体短暂僵住 | `raised eyebrows, wide-open eyes, dropped jaw` |
| 疑惑 | 单侧眉毛上扬（或眉毛皱起），头部微偏，目光游移 | 手指轻敲桌面 | `one eyebrow raised, head tilted, squinting eyes` |
| 焦虑 | 眉头紧锁，眼神闪烁/不安地扫视，咬唇或喉结滚动 | 手指无意识搓动，步伐急促 | `furrowed brows, darting eyes, fidgeting hands` |
| 厌恶 | 鼻子皱起，上唇抬起，嘴角下拉 | 身体后倾，转头 | `wrinkled nose, curled upper lip, turning away` |

### 三招让角色活过来（来源：抖音采集）

**1. 控制情绪强度**
- 避免 AI 默认情绪最大值（容易假）
- 在提示词中加入强度修饰：`slightly`, `barely perceptible`, `subtle`
- 示例：`a faint smile barely lifting the corners of his mouth`

**2. 给微表情一个发生原因**
- 微表情不能孤立存在，需要与场景/对白联动
- 加入触发条件的描述：`upon hearing the news, her eyes widened`
- 加上半身动作，让画面脱离摆拍感

**3. 给情绪加时间顺序**
- 描述情绪的变化过程：`from confusion to realization`
- 示例：`His expression shifted from doubt to shock as the truth sank in`

### 表情拆解法（来源： AICG造梦局）

将复杂表情拆解为多个微动作组合：
```
害羞抿嘴笑 = 嘴唇闭合 + 唇缝紧贴 + 嘴角微微上扬 + 
             肩膀微耸 + 下巴内收 + 眼神先向下看再猛抬
```

### 提示词公式

```
人物微表情 = 主体 + 面部参数(眉毛/眼睛/嘴巴) + 情绪强度 + 
             触发原因 + 身体动作 + 时间变化
```
