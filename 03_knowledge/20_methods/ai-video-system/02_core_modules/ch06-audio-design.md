# Ch6: 音频设计——让"声音"提升质感

> 结果导向：从"听觉成果"反推声音设计的参数与指令

---

## 核心知识

### 音频三角

```
音频设计 = 对白(人声) + 环境音(氛围) + 背景音乐(情绪)
```

### 背景音乐：情绪匹配

| 目标情绪 | 音乐风格 | 节奏(BPM) | 乐器 | 参考音量 |
|---------|---------|-----------|------|---------|
| 紧张悬疑 | 悬疑氛围 | 60-80 BPM | 低音弦乐、电子合成器 | 30-35dB |
| 悲伤低潮 | 抒情慢板 | 60-70 BPM | 钢琴、大提琴独奏 | 30-35dB |
| 热血激昂 | 摇滚/交响 | 120-140 BPM | 电吉他、鼓、管弦乐 | 40-45dB |
| 史诗宏大 | 管弦乐 | 80-100 BPM | 铜管、弦乐群、合唱 | 35-40dB |
| 温馨日常 | 轻音乐 | 80-100 BPM | 吉他、钢琴、口琴 | 25-30dB |
| 赛博朋克 | 电子合成器 | 100-130 BPM | 合成器、鼓机、电子音效 | 35-40dB |
| 奇幻梦幻 | 氛围电子 | 70-90 BPM | 空山人声、竖琴、pad | 25-35dB |

### 卡点原则

- 快镜头 → 配乐 120BPM+，鼓点清晰，每拍一个转场
- 慢镜头 → 配乐 60BPM，旋律舒缓，4拍一个转场
- 场景切换 → 配乐节奏变化或乐器变化做标记

### 环境音分类

| 场景 | 环境音 | 作用 |
|------|-------|------|
| 雨夜 | 雨声(密集/稀疏) + 雷声(远近) + 潮湿脚步声 | 营造孤独/悬疑 |
| 咖啡厅 | 杯碟碰撞 + 背景交谈(模糊) + 咖啡机蒸汽声 | 温馨日常感 |
| 城市街头 | 车流声 + 脚步声 + 店铺音乐(远处) | 真实生活感 |
| 森林 | 鸟鸣 + 风声穿林 + 落叶声 | 宁静自然感 |
| 太空舱 | 机械嗡鸣 + 电子警示音 + 循环呼吸声 | 科幻科技感 |
| 恐怖屋 | 地板吱呀 + 滴水声 + 低频嗡鸣 | 营造恐惧 |

### 对白参数

- 音色选择：低沉/清脆/沙哑/温暖
- 语速：快(紧张)/中(叙述)/慢(深沉)
- 音量：对白通常比背景音乐高 10-15dB
- 混响：小空间(无混响)/大厅(短混响)/空旷(长混响)

### 声音的叙事性

声音可以推动叙事：
- 紧张感构建：环境音渐强 + 配乐节奏加快 + 对白断句变短
- 情绪转折：配乐突然停止 → 静默2秒 → 换曲入场
- 场景切换：环境音交叉渐变（前一场景音渐弱+后一场景音渐强）
