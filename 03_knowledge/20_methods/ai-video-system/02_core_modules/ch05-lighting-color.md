---

## 情绪→光影映射

```
孤独感 → 冷色调(蓝/灰) + 高对比度 + 侧光 + 大面积阴影
温馨感 → 暖光(橙/黄) + 柔焦 + 低对比 + 漫反射
悬疑感 → 冷绿光 + 高对比 + 硬光 + 闪烁光源
史诗感 → 金色光 + 低角度 + 长阴影 + 暖色调
科技感 → 冷蓝光 + 霓虹光晕 + 高饱和 + 自发光元素
怀旧感 → 暖黄光 + 颗粒感 + 柔光 + 低保和
压迫感 → 顶光 + 高对比 + 硬阴影
梦幻感 → 柔光 + 浅景深 + 暖色调渐变
```
