### Ch3: 基础定调参数

**结果导向**: 不同成果的参数选型：
- 电影级质感 → ARRI Alexa + 柯达5219参数
- 动漫风 → 赛璐璐质感+手绘笔触参数
- 赛博朋克 → 霓虹色调+高对比度

**现有知识**: 可灵模型版本对照（1.0→4K）、各版本适用场景

**采集方向**:
- [ ] 不同视频风格的参数配置方案
- [ ] 分辨率、帧率、比例的最佳实践
- [ ] 多平台（抖音/B站/YouTube）的出图参数差异

### Ch4: 分镜时序与运镜

**结果导向**: 
- 紧张追逐戏 → 分镜节奏快+手持运镜
- 抒情慢镜头 → 固定机位+长镜头

**现有知识**: 十大万能镜头运动、三分法构图、景别控制情绪曲线、Seedance长镜头转场

**采集方向**:
- [ ] 更多运镜类型与效果对照
- [ ] AI视频的分镜叙事节奏控制
- [ ] 多镜头连贯性的提示词方案

### Ch5: 光影色调

**结果导向**:
- 孤独感 → 冷色调+高对比度
- 温馨感 → 暖光+柔焦
- 史诗感 → 金色光+低角度

**现有知识**: 邵氏电影美学（依士曼胶片+高调硬光）、视听语言提示词

**采集方向**:
- [ ] 情绪→光影的精准映射表（扩展版）
- [ ] 色彩理论的 AI 适配方案
- [ ] LUT 调色在 AI 视频中的应用

### Ch6: 音频设计

**子章节**:
- 6.1 对白：音色、音量、情绪的参数化
- 6.2 环境音：场景氛围感的关键
- 6.3 背景音乐：情绪/风格/节奏/乐器的精准匹配
- 6.4 声音的叙事性：从结果反推声音设计

**结果导向**:
- 悲伤场景 → 慢节奏弦乐，35dB
- 热血场景 → 快节奏摇滚，45dB
- 史诗感 → 管弦乐
- 赛博朋克 → 电子合成器

**采集方向**:
- [ ] AI 视频音频设计的完整方法论
- [ ] 背景音乐的情绪映射表
- [ ] 环境音对场景氛围的增强技巧
- [ ] 各平台音频参数标准

### Ch7: 人物塑造

**子章节**:
- 7.1 人物形象：外貌、服饰、体态的参数化
- 7.2 微表情与动作细节：让角色"有灵魂"

- 疑惑 → 皱眉

**采集方向**:
- [ ] 微表情的完整参数化列表
- [ ] 动作细节与情绪的对应关系
- [ ] AI 角色一致性解决方案
- [ ] 多人互动场景的提示词设计

### Ch12: 大模型差异与适配

**结果导向选型**:

- 复刻电影风格/工业级短片 → Gen-2，提示词+参考图双输入

### Ch14: 创意→AI友好型脚本

**核心方法**:
- 脚本模块化结构：分镜+动作+情绪+光影+音频
- 小说转脚本：从"文字叙事"到"视觉叙事"
- 场景控制：从大场景到细节锚点的拆解

**示例**:
```
小说: "他在雨夜的巷子里奔跑，心跳如鼓"
→ 提示词: "0-5秒，中景跟拍，男性在雨夜巷奔跑，脚步急促，镜头轻微晃动；
   光影：雨夜冷光，地面水洼反光；音频：雨声(密集) + 心跳声(低频，渐强)"
```

**采集方向**:

- [ ] 场景氛围描述的词汇库
- [ ] 多场景互动的参数化描述
