## 核心知识

### 角色生成万能公式

```
角色 = [核心描述] + [面部细节] + [发型发色] + [服装配饰] + [风格质感] + [光影氛围]
```

| 要素 | 描述 | 示例 |
|------|------|------|
| 核心描述 | 年龄+身份 | 20岁剑客、高冷霸总 |
| 面部细节 | 肤色、眼神、瞳色、五官 | 冷白皮、深邃眼神、丹凤眼 |
| 发型发色 | 长度、质感、细节 | 根根分明黑发、蓬松、碎发 |
| 服装配饰 | 材质、装饰、道具 | 锦缎、刺绣、珠宝、剑 |
| 风格质感 | 画风+精度 | 高级CG插画、BJD质感、伪厚涂、8K |
| 光影氛围 | 视角+光线+环境 | 逆光、丁达尔效应、暴雪 |

### 角色一致性（三视图法）

防止角色在不同镜头下"翻车"：

1. **标准全身照**
   - 公式：[角色描述]，正面全身站立标准照，纯白背景，9:16
   - 目的：锁定体型、服饰、比例

2. **多角度三视图**
   - 公式：[角色描述]，正面+侧面+背面全身照+面部特写，16:9
   - 目的：为 AI 提供全方位"建模参考"

3. **质感升级**
   - 加入"次表面散射(SSS)"或"BJD质感" → 告别塑料皮
   - 加入"轮廓光"+"丁达尔效应"+"强烈明暗对比" → 空间深度

### 风格一致性要点

> **风格越写实 → 角色一致性越高**
> **风格越风格化（二次元等）→ 角色一致性越低**

实操建议：
1. 追求稳定性首选写实风格
2. 必须使用风格化时不要频繁切换风格
3. 先确定基础风格，后续用同一风格设定
4. 提示词中明确要求"保持角色一致"

### 动漫分镜的提示词适配

| 分镜类型 | AI适配方式 |
|---------|-----------|
| 角色特写 | 锁定面部特征+表情参数 |
| 动作场景 | 明确运动轨迹+物理效果 |
| 场景切换 | 保持角色一致性描述 |
| 情绪镜头 | 光影+微表情联动 |

### AI漫剧完整工作流

```
剧本(Qwen/豆包) → 分镜拆解 → 角色设计(三视图) → 
提示词生成 → AI视频(即梦/可灵/Pika) → 剪辑合成
```
