## 二、电影美学风格库

### 邵氏电影美学（来源：既有知识）

**三大风格要素**：
```
依士曼彩色胶片：强制AI还原高饱和度复古影像特征
高调硬光+舞台戏剧化光影：打造侠客风骨与画面张力
高度人工化影棚置景+材质混搭：还原古典舞台意境
```

**核心关键词**：
```
依士曼彩色胶片, 强烈的舞台戏剧, 高调硬光, 
高度人工化的影棚置景, 材质混搭, 邵氏电影美学, 
复古高饱和度影像, 侠客风骨, 戏剧光影张力, 古典舞台意境
```

### 经典电影风格参考

| 风格 | 提示词锚点 | 光影特点 |
|------|-----------|---------|
| 赛博朋克 | cyberpunk, neon, rain, tech noir | 冷蓝+霓虹+高对比 |
| 胶片质感 | film grain, 35mm, vintage color grading | 暖色调+颗粒感 |
| 纪录片自然风 | documentary, natural light, handheld | 自然光+真实色彩 |
| 黑色电影 | film noir, high contrast, low key | 单色+高对比+硬阴影 |
| 科幻史诗 | sci-fi, epic scale, anamorphic | 冷色调+宏大光影 |

## 三、电影级参数

### 镜头参数

```
镜头焦距：16mm(广角)/35mm(标准)/50mm(人像)/85mm(特写)/200mm(长焦)
光圈：f/1.2(浅景深虚化) / f/8(全景清晰)
画幅：2.35:1(电影宽银幕) / 16:9(电视) / 4:3(复古)
```

### 常用电影质感情号

```
cinematic, film grain, 35mm, anamorphic lens, shallow depth of field, 
bokeh, dramatic lighting, color graded, vintage film stock, 
Kodak Portra, Fuji Superia, ARRI Alexa, IMAX
```

## 四、分镜与叙事

### 好莱坞经典三幕式

```
第一幕(25%)：建立世界观+角色引入 → 远景+中景
第二幕(50%)：冲突发展+角色成长 → 中景+近景+特写
第三幕(25%)：高潮+结局 → 特写+远景
```

### 景别→情绪映射（来自李导V4）

```
远景→近景→远景：励志氛围
中景→近景→特写：紧张氛围
远景→特写：戏剧性(震惊/发现/转折)
特写→远景：情绪释放/留白
```
