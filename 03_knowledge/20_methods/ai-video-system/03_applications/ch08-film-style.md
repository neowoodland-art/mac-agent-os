# Ch8: 电影风格AI视频创作

> 结果导向：从"想要的电影感"反推画质参数+镜头语言+光影方案

---

## 一、电影级提示词结构

### 九要素顺序（从入门到精通）

```
主体 → 场景环境 → 情绪氛围 → 镜头语言 → 运动方式 → 
光影质感 → 画面细节 → 风格标签 → 分辨率
```

| # | 要素 | 说明 | 示例 |
|---|------|------|------|
| 1 | 主体 | 穿着/材质/表情，越具体越好 | 破旧机甲的拾荒者 |
| 2 | 场景环境 | 年代/地点/天气 | 黄沙漫天的废墟长城 |
| 3 | 情绪氛围 | 感受性词汇 | 压抑/热血/孤寂 |
| 4 | 镜头语言 | 景别+角度 | 极低角度仰拍 |
| 5 | 运动方式 | 镜头移动 | 缓慢推镜头(Dolly In) |
| 6 | 光影质感 | 光源方向/颜色/亮度 | 体积光，高对比度 |
| 7 | 画面细节 | 真实感小元素 | 划痕/灰尘/水滴 |
| 8 | 风格标签 | 整体视觉 | 废土美学/超写实 |
| 9 | 分辨率 | 画质 | 8K/4K |

## 二、电影级术语库

### 景别体系

| 景别 | 效果 | 使用场景 |
|------|------|---------|
| 大远景 | 突出整个世界环境 | 开场建立时空感 |
| 广角镜头 | 容纳更多环境 | 展现宏大场面 |
| 中景 | 人物上半身 | 对话/动作 |
| 特写 | 突出表情/纹理 | 情绪高潮 |
| 极特写 | 放大微观细节 | 悬疑/强调 |

### 镜头运动

| 运动 | 效果 | 使用场景 |
|------|------|---------|
| Dolly In（推） | 慢慢靠近主体，增加紧张感 | 悬疑/高潮 |
| Dolly Out（拉） | 慢慢后退，展现更多环境 | 揭示全貌/失落 |
| Tracking Shot（跟拍） | 镜头跟随主体移动 | 动作/追逐 |
| Slow Motion（慢动作） | 放慢动作放大张力 | 动作高潮/情绪 |
| Orbit（环绕） | 镜头围绕主体旋转 | 展示主体/建立气势 |
| Crane（升降） | 从低到高或从高到低 | 开场/结尾 |

### 光影术语

| 术语 | 效果 | 应用场景 |
|------|------|---------|
| 体积光 | 光有具体形态（光束） | 穿透沙尘/森林 |
| 侧逆光 | 突出边缘轮廓 | 人物/产品 |
| 硬光/高对比 | 阴影清晰，明暗反差大 | 悬疑/黑色电影 |
| 冷色调(蓝灰) | 冷静/孤独/科技感 | 科幻/悬疑 |
| 暖色调(橘红) | 温暖/怀旧/史诗感 | 日落/回忆/史诗 |
| 浅景深 | 背景虚化突出主体 | 特写/人物 |

## 三、五个电影级案例模板

### 案例1：东方废土史诗

```
黄沙漫天的废墟长城，残破的机械巨龙骨架半掩在沙丘中。
一名身穿破旧中式机甲的拾荒者，正用力拖拽着一根粗重的金属缆绳。
极低角度仰拍，缓慢推镜头(Dolly In)。
斜射的刺眼阳光穿透强沙暴形成清晰的体积光，高对比度。
电影级沙尘粒子物理特效，浅景深虚化背景，浓重的胶片颗粒。
废土美学，超写实，8K分辨率。
```

### 案例2：极致微距商品（商业广告TVC）

```
一块机械腕表悬浮在深邃的纯黑无重力空间中。
表盘内部的陀飞轮与齿轮正在精准地咬合运转。
极特写微距镜头，缓慢推进并环绕(Slow Orbit)。
戏剧性的侧逆光聚光灯，仅照亮金属齿轮的物理边缘。
极浅景深，剔透的蓝宝石玻璃折射，8K商业大片质感。
```

### 案例3：心理惊悚/悬疑

```
暴雨倾盆的深夜，一辆停在树林深处的汽车内部。
驾驶座上的男人双手紧紧抓着方向盘，眼神惊恐。
车内视角向外拍摄，缓慢拉近面部。
微弱的冷蓝色路灯光透过雨水折射在男人脸上。
失焦与重新对焦的镜头呼吸感，高反差冷色调。
胶片质感，4K。
```

### 案例4：极致自然风光

```
冰岛黑沙滩，狂暴的深蓝色巨浪拍打着黑色玄武岩石柱。
镜头从一块黑色礁石上的冰块快速拉远(Dolly Out)并向高空垂直拉升，
揭示整片冰雪覆盖的海岸线和远处喷发的暗红色火山。
冷酷的蓝灰调自然光，史诗级广角，极致慢动作。
国家地理级别清晰度，8K超写实。
```

### 案例5：动态武侠美学

```
深夜暴雨竹林，女剑客被黑衣人重重包围。
广角镜头快速环绕半圈(Fast Orbit)建立肃杀氛围。
转为侧面稳定跟拍(Tracking Shot)，剑客拔剑穿梭。
极特写捕捉剑刃劈开雨滴的瞬间，极致慢动作放大张力。
冷酷幽蓝色月光，极高对比度光影，水墨暗黑武侠美学。
8K超写实电影现实主义。
```

## 四、四个必须避免的坑

| ❌ 错误 | ✅ 修正 | 原因 |
|---------|---------|------|
| "大远景"+"背景虚化" | 统一景别描述 | AI按物理规律，矛盾指令混乱 |
| "一个女人站着" | "胸口起伏，衣角被风吹动" | 静态无动作 → 人物僵硬 |
| 不写光照 | 指定光源方向+类型+颜色 | AI默认平光，画面无立体感 |
| "绝美/震撼"等主观词 | 直接使用具体参数 | 稀释核心指令权重 |

## 五、邵氏电影美学（既有知识）

**三大风格要素**：
```
依士曼彩色胶片 → 高饱和度复古影像
高调硬光+舞台戏剧化光影 → 侠客风骨与画面张力
人工化影棚置景+材质混搭 → 古典舞台意境
```

**核心关键词**：
```
依士曼彩色胶片, 高调硬光, 舞台戏剧光影, 高度人工化的影棚置景,
材质混搭, 邵氏电影美学, 复古高饱和度影像, 侠客风骨
```
