## 一、科幻风格提示词大全

```
[场景/主体描述] + [核心科技/科幻元素] + [光影/氛围技术] +

```

## 三、奇幻风格创作

### 通用奇幻模板

```  
[场景/生物] + [魔法元素] + [奇幻光影] + [风格参数]
```

### 经典奇幻类型

| 类型 | 核心关键词 |
|------|-----------|
| 精灵仙境 | ethereal forest, glowing mushrooms, fairy lights, magical atmosphere |
| 黑暗魔幻 | dark fantasy, gothic castle, misty graveyard, eerie atmosphere |
| 龙与魔法 | dragon lair, ancient ruins, magic runes, elemental magic |
| 史诗战场 | epic battle, medieval army, siege weapons, dramatic sky |

### 常见错误与修正

| ❌ 避免 | ✅ 推荐 |
|---------|--------|
| 仅用"futuristic"笼统词汇 | 定义具体科技时代/风格(cyberpunk/solarpunk) |
| 忽略灯光 | 包含灯光氛围描述(volumetric fog/neon glow) |
| 混合不兼容风格 | 参考知名作品锚定(Blade Runner inspired) |
| 元素过度堆叠 | 添加具体环境细节(rain-slicked streets) |
