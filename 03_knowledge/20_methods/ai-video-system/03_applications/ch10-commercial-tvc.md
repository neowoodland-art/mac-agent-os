# Ch10: 商业广告/TVC创作

> 结果导向：从"品牌调性"反推画面风格+产品卖点+情绪传递

---

## 一、AI-TVC完整工作流

### 5步出品（20分钟内）

```
生成提示词 → 生成图片(豆包) → 图片处理(去水印+高清化) → 
图生视频(即梦/可灵) → 剪辑合成(剪映)
```

**工具链**：
| 步骤 | 工具 | 作用 |
|------|------|------|
| 生成提示词 | ChatGPT/豆包 | 获取精确的图片描述 |
| 生成图片 | 豆包/即梦 | 生成高质量分镜图 |
| 图片处理 | 百度AI助手 | 去水印+高清化 |
| 图生视频 | 即梦/可灵 | 静态图转动态视频 |
| 剪辑合成 | 剪映 | 配乐+字幕+调色 |

### 核心：运镜提示词

在动作提示词中**必须加入运镜描述**，让镜头"讲故事"：
```
❌ 老奶奶走路
✅ 老奶奶推着车子一直往前走，镜头跟随老奶奶
```

---

## 二、TVC提示词结构

### 标准格式

```
[主体描述] + [动作细节] + [场景环境] + [产品卖点] + [光影氛围] + [画风尺寸]
```

### 示例：像素风TVC

```
画面主体描述（老奶奶、推车、手中核聚变原子）
+ 背景描述（店铺、街上行人）
+ 天空远景（白玉京全息图）
+ 画风与尺寸（像素画风格，9:16）
+ 光效（液态银色金属、蓝色能量核心发光）
```

### 玉石品牌TVC（来自既有知识）

利用AI提示词可快速生成品牌独立站TVC广告短片：
- 结合中式色彩美学
- 电影感构图
- 专业LUT调色提升品质
- Seedance 2.0 生成电影级画面

## 三、商业广告类型与策略

| 广告类型 | 核心策略 | 推荐工具 |
|---------|---------|---------|
| 品牌宣传片 | 电影级质感+品牌调性 | Runway+Kling |
| 产品演示 | 产品细节+功能展示 | Pika(区域动画) |
| 促销短视频 | 快速出片+高信息量 | 即梦+Kling |
| 电商主图视频 | 高清产品图+简洁动画 | 即梦 |

### 高级技巧

1. **图片先行**：先用高质量生图工具打好画面基础
2. **动作提示词含运镜**：让静态图"活"起来的关键
3. **后处理统一调性**：剪映统一调色+LUT
4. **多次迭代**：每次只改5%内容AB测试
