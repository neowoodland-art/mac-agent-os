# Ch1: AI视频生成的"执行本质"与结果推导逻辑

> 核心问题：AI 不是读心术，指令的明确性决定输出上限。

---

## 一、底层逻辑：从"脑内画面"到"机器指令"

### 1.1 信息传递模型

```
创作者愿景(模糊画面) → 编码(撰写提示词) → AI解码(算法生成) → 
输出视频 → 对比检验 → 迭代微调(黄金法则5%:每次只改5%)
```

这不是单向输出，而是人机协作的**迭代反馈回路**。

### 1.2 提示词基础公式

```
提示词 = 主体(谁) + 场景(在哪) + 运动(做什么)
```

这是搭建视频骨架的基石。在此基础上注入"导演思维"：
- **观察视角**：告诉 AI 从哪个角度看
- **情感基调**：告诉 AI 什么情绪氛围
- **时间线索**：告诉 AI 变化过程

### 1.3 AI不是全能助手，是精确执行者

| 人类思维 | AI思维 |
|---------|--------|
| 联想、模糊、本能理解 | 字面、精确、逐条执行 |
| 看到"雨夜"→潮湿/寒意/孤独 | 看到"雨夜"→雨和夜两个元素 |
| 喜欢概括描述："做得好一点" | 需要量化细节："仰视、逆光、0.5倍速" |
| 基于感受的内在直觉 | 基于指令组合的外在运算 |
| 信息过载时会概括提炼 | 信息过载时会混乱冲突 |

### 1.4 为什么AI需要明确指令

1. **缺乏常识和联想能力**：输入"一个人走路"，AI可能生成任何场景
2. **信息过载阈值**：超过5个核心信息、3组动态元素、10个修饰词 → AI无法聚焦
3. **时空错乱**：缺少明确的空间/时间过渡描述 → 画面跳跃
4. **文化差异**：AI训练数据的文化背景可能与你不同

---

## 二、提示词信息传递模型

### 2.1 逆向编码闭环

```
步骤1：解构 → 将愿景分解为主体/场景/运动
步骤2：注入 → 加入镜头语言、氛围调色盘、风格化基因
步骤3：设定边界 → 使用负面清单防止跑偏
步骤4：检验 → 对比生成视频与源点愿景
步骤5：迭代 → 每次只改5%的关键词进行AB测试
```

### 2.2 核心原则

- **不要告诉AI你想要什么，而是教会AI如何用它的方式构建出你想要的画面**
- **把AI当作一个精确执行者，而不是全能助手**
