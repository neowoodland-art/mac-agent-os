# Ch18: 常见问题解决方案库

> 结果导向：从"不想看到的成果"反推修复方案

---

## 核心问题分类

### A. 画面类问题

#### A1. 人脸变形/身份漂移

| 症状 | 修复方案 | 优先级 |
|------|---------|-------|
| 人脸扭曲变形 | 提供清晰角色**参考图**锁定身份 | ⭐⭐⭐ |
| 不同镜头角色变脸 | 使用静止或缓慢移动的镜头 | ⭐⭐⭐ |
| 面部特写变形严重 | 减少面部特写时长，动态场景切换镜头 | ⭐⭐ |
| 首帧OK后续崩 | 用第1帧好的脸作为参考图重生成 | ⭐⭐⭐ |

**提示词修复**：
```
[角色描述]，面部始终保持完全一致，无变形。
```

#### A2. 物体漂移/元素消失

| 症状 | 修复方案 | 优先级 |
|------|---------|-------|
| 物体位置随机漂移 | 提示词中**文字锚定**关键物体 | ⭐⭐⭐ |
| 物体中途消失 | 最小化画面中物体数量 | ⭐⭐ |
| 场景元素乱变 | 使用**静态构图**(锁定机位) | ⭐⭐⭐ |
| 长视频不一致 | 生成更短的片段(3-5秒)后拼接 | ⭐⭐⭐ |

**提示词修复**：
```
红色咖啡杯始终保持在桌子上，位置固定不变。
```

#### A3. 光影闪烁/曝光变化

| 症状 | 修复方案 | 优先级 |
|------|---------|-------|
| 光照忽明忽暗 | 提示词指定光照：持续柔和的日光从左侧照射，无光照变化 | ⭐⭐⭐ |
| 多光源打架 | 使用单一光源，室内场景更稳定 | ⭐⭐ |
| 画面闪烁 | 使用平光风格，避免戏剧性光照 | ⭐⭐ |

**后期补救**：调色工具统一曝光。

#### A4. 画面风格跑偏

- **检查参考示例**是否明确
- **换适配大模型**（如写实→Kling，动漫→Pika）
- 提示词加入风格锚点：`cinematic, photorealistic, anime style`

---

### B. 运动类问题

#### B1. 不自然动作/飘忽运动

| 症状 | 修复方案 | 优先级 |
|------|---------|-------|
| 动作漂浮感 | 提示词明确描述物理效果：沉重的脚步声，可见的地面冲击 | ⭐⭐⭐ |
| 运动逻辑诡异 | 参考真实运动：像一个疲惫的人提着购物袋走路 | ⭐⭐ |
| 与环境无交互 | 包含环境交互：脚踢起灰尘，手按入靠垫 | ⭐⭐ |
| 动作过快看不清 | 放慢动作速度，隐藏飘忽感 | ⭐ |

#### B2. 手部与手指问题

- **裁剪手部**或让其失焦
- 使用简单手部姿势（握拳、张开手掌）
- **避免手部特写**，使用广角镜头
- **多次生成并挑选**最佳版本

#### B3. 时间不一致性（"梦境"效果）

- **分段生成**：3-5秒片段后拼接
- 每个片段**重复关键视觉描述符**
- 使用**相同种子**保证一致起点
- 应用**风格参考帧**

---

### C. 音频类问题

| 问题 | 修复方案 |
|------|---------|
| 背景音乐盖过对白 | 降低音乐音量，提升对白混响清晰度 |
| 音画不同步 | 检查视频帧率与音频时间轴对齐 |
| 环境音违和 | 根据场景选择匹配的环境音类型 |
| AI配音无情感 | 加入语气/情绪描述参数 |

---

### D. 工具类问题

| 问题 | Workaround |
|------|-----------|
| 排队时间过长 | 选择低峰时段/换用替代工具 |
| 生成失败/报错 | 缩短提示词至50-100词 |
| 风格不符合预期 | 换用更适配的大模型 |
| 角色一致性差 | 切换到Pika(多镜头锚点)或Kling(人脸模型) |

## 提示词优化技巧

### 1. 明确指出"什么不应该改变"

```
光照始终保持恒定
角色外观保持完全一致
机位固定，无运动
```

### 2. 描述物理效果，而非仅视觉

```
❌ "一个球弹跳"
✅ "一个橡皮球落下，撞击地面时压缩，并以递减的高度弹回"
```

### 3. 使用电影语言

```
中景，锁定机位，50mm镜头
缓慢推进，平稳运动
自然光，无人工光源
```

### 4. 包含时间锚点

```
场景开始于...然后...最后...
在整个片段中始终...
在任何时候都不要...
```

### 5. 文字与Logo

- ❌ 不要在视频中生成文字
- ✅ 务必在后期添加
- 模糊或隐藏Logo
