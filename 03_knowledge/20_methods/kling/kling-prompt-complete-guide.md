## 第一章：可灵AI提示词核心公式

### 1.1 通用公式结构

提示词 = 主体（主体描述）+ 运动 + 场景（场景描述）+（镜头语言 + 光影 + 氛围）

三层递进公式：

| 层级 | 公式 | 示例 |
|------|------|------|
| 基础层 | 主体 + 场景 + 主体运动 | 一个小男孩在咖啡厅看书 |
| 细节层 | 主体描述 + 场景物品 + 动作细节 | 穿着红色衣服的小男孩在咖啡厅看书，桌上有一只咖啡杯正冒着热气 |
| 质感层 | 基础 + 细节 + 镜头语言 + 光影 + 氛围 | +正面镜头+背景虚化+氛围光照 |

### 1.2 5W1H 提示词法

| 要素 | 含义 | 示例 |
|------|------|------|
| Who | 画面主体，必须明确 | 穿着睡衣的少女 |
| What | 主体正在做什么 | 优雅地坐在椅子上 |
| When | 时间背景 | 暮春的雨夜 |
| Where | 地点环境 | 在公寓里 |
| Why | 行为动机/情绪 | 正在家里加班工作 |
| How | 方式/风格 | 赛博朋克风格、冷色调 |

> 描述越详细越精准，生成效果越符合预期。

### 1.3 六大核心要素（编剧视角）

1. 主体：谁在画面中？主角/配角的特征
2. 构图与角度：黄金分割点、低角度、仰视视角
3. 照明与色彩：柔和的侧光、赛博朋克冷色调
4. 运动：摄像机镜头运动 + 画面中物体的运动
5. 背景：场景环境、时间、氛围
6. 氛围感：整体情绪、光影氛围

## 第二章：可灵提示词进阶技巧

### 2.1 语言风格原则

- 语言简洁：用简单的词语和句子，避免复杂长句
- 顺序清晰：主体→场景→运动→镜头语言的顺序
- 避免歧义：不省略关键信息
- 细节优先：先保证核心内容，再逐步添加细节

### 2.2 十大万能镜头运动提示词

| # | 运动类型 | 描述方式 |
|---|---------|---------|
| 1 | 推进镜头 | 摄像机缓慢向前推进 |
| 2 | 拉远镜头 | 摄像机向后拉远 |
| 3 | 旋转镜头 | 环绕主体旋转拍摄 |
| 4 | 跟随镜头 | 跟随主体运动 |
| 5 | 摇晃镜头 | 手持摄影风格摇晃 |
| 6 | 穿越镜头 | 摄像机穿越景物 |
| 7 | 第一人称视角 | POV 视角 |
| 8 | 动感模糊 | 搭配高速运动的模糊效果 |
| 9 | 升降镜头 | 从低到高或从高到低 |
| 10 | 希区柯克变焦 | 推拉+变焦同时进行 |

### 2.3 穿越机效果关键词

摄像机穿越 + 景物 + 第一人称视角 + 动感模糊 + 旋转 + 高速飞行

## 第四章：实战技巧

### 4.1 一句话出片法

1. 确定一句可跑通的核心提示词
2. 保持核心不变，仅更换运镜方式批量生成
3. 连续输入 10-20 次获取多组镜头
4. 剪辑成完整短片

### 4.2 四格超短片

第1句：场景建立（远景）→ 第2句：人物出场（中景）
第3句：动作发展（近景）→ 第4句：高潮/结尾（特写）

### 4.3 首尾帧控制

1. 上传第一帧图片（角色/场景）
2. 上传最后一帧图片（目标画面）
3. 填写中间过程的提示词
4. AI 自动生成从首帧到尾帧的完整过渡

> 首尾帧是控制画面精确度的最强手段。

### 4.4 运镜控制 + 运动笔刷

- 运镜控制：告诉摄像机怎么动
- 运动笔刷：告诉画面里的物体怎么动
- 先用笔刷圈定物体，再指定运动方向

### 4.5 多镜头工作流（3.0）

1. 编写详细的场景提示词
2. 设置多个镜头标记
3. 每个镜头独立描述运镜和情绪
4. 一键生成多镜头连续视频

### 4.6 避免画面变形

| 问题 | 解决方案 |
|------|---------|
| 人物面部变形 | 使用首尾帧锁定面部结构 |
| 物体扭曲 | 减少高速运动描述 |
| 比例失调 | 添加量化占比描述 |
| 闪烁跳变 | 使用参考图+低运动幅度 |

## 第五章：专题技巧

### 5.1 角色一致性

1. 人脸模型训练：定制专属 AI 模特
2. 首尾帧锁定：每次生成都参考同一张角色图
3. 描述锁定：固定面部、发型、身材比例
4. 全片不改：全程不改变身份与面部结构

### 5.2 图生视频

- 提供图片 + 提示词控制
- 单次生成 5 秒，可多次延长
- 提示词理解优秀，动态呈现丰富

### 5.3 音效生成

- 视频生成完成后自动匹配音效
- 支持场景音效（风声、水声、环境音）
- 可单独调整音效强度

### 5.4 数字人功能

1. 上传人物照片/视频
2. 填写对口型文本
3. 选择数字人风格
4. 一键生成说话/唱歌视频

### 5.5 工具链整合

## 附2：Kling 3.0 提示词完全指南（2026版）

> 采集自: seavidgen.com / soravideo.art — Kling 3.0 官方社区最佳实践

### 一、Kling 3.0 7大提示词要素

| # | 要素 | 说明 | 示例 |
|---|------|------|------|
| 1 | 主体细节 | 身体特征+服装+表情 | "30岁出头女性，齐肩红褐色头发，深灰羊毛大衣，勃艮第红围巾，神情自信" |
| 2 | 环境场景 | 地点+建筑+天气+氛围 | "黄昏白雪覆盖的都市街道，维多利亚砖房，橱窗透出暖光" |
| 3 | 光照规格 | 光源+方向+色温+强度 | "黄金时刻阳光"、"戏剧性侧光+深重阴影" |
| 4 | 镜头移动 | 电影术语描述 | "中景，缓慢推镜头转特写，平视视角" |
| 5 | 动作强度 | 0-3级数值 | 细微动作0.3-0.5，高能动作2.0-3.0 |
| 6 | 风格色调 | 美学+情感基调 | "温暖色阶，略微低饱和度" |
| 7 | 音频元素 | 声音+情感+环境音 | "女性中音，热情语调，细微城市环境音" |

### 二、Kling 3.0 动作控制（核心差异化优势）

**工作原理**：上传参考视频 → Kling提取运动数据(姿态/轨迹/节奏) → 应用到新场景。

**实操流程**：
1. 录制或找一段展示目标动作的参考视频（背景简单、肢体清晰为佳）
2. 在生成面板上传到"动作控制"区域
3. 编写提示词：只描述角色/场景/风格，**不描述具体动作**
4. 动作强度参数：0-3级，从温和慢速开始

**关键参数**：`动作强度 0-3` — 细微动作用0.3-0.5，高能动作用2.0-3.0。

### 三、多镜头序列编写

Kling 3.0 支持最多 **6 个镜头**，自动保持角色和环境一致性。

**结构模板**：
```
镜头1（5s）：远景室外全景，缓慢推近...
镜头2（5s）：中景跟拍主体，平视...
镜头3（5s）：面部特写，固定镜头...
```

**每个镜头需指明**：
1. 编号和时长
2. 构图和机位
3. 主体和关键动作
4. 镜头运动类型（推/拉/摇/移/固定）
5. 切换类型（切镜/淡入淡出/叠化）

### 四、四要素提示词公式

```
主体和动作 + 镜头运动 + 灯光氛围 + 风格参考
```

**产品展示示例**：
```
A pair of white wireless headphones floating and slowly rotating
against a clean gradient background, soft studio lighting from above
creating subtle shadows, gentle particles drifting in the air,
product photography style, 4K
```

**角色场景示例**：
```
A woman in a dark jacket walking through a rainy Tokyo street at night,
neon signs reflecting on wet pavement, camera following from behind
in a slow tracking shot, shallow depth of field, cinematic color grading
```

### 七、Kling 3.0 常见问题

| 问题 | 解决方法 |
|------|---------|
| 慢动作 | 提示词中明确速度, 时长与动作量匹配 |
| 口型同步差 | 对话限制在5秒内, 或多镜头拆分为正反打 |
| 提示词被拒绝 | 移除暴力/敏感词, 用中性语言描述 |
| 角色不一致 | 使用 Elements 上传面部参考, 多镜头中引用 |
| 运动模糊 | 添加"动作模糊"到正向词, 或用参考视频 |
