Python 装饰器是一种强大的工具，允许在不修改原函数代码的情况下，为函数添加额外的功能。

## 基本语法

```python
@decorator
def my_function():
    pass
```

## 应用场景

1. 日志记录
2. 性能测试
3. 权限验证
4. 缓存机制

## 技术要点

装饰器本质上是一个接受函数作为参数并返回函数的函数，使用了 Python 的闭包特性。
