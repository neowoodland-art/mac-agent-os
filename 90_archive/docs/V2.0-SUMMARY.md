# AgentOS v2.0 最新说明汇总

最后更新：2026-04-28

## 1. 当前版本是什么

AgentOS v2.0 是当前仓库的稳定可运行基准版。

它不是最初的单机原形，也不是未来多机协同终态，而是已经落地并能恢复的一版正式基线。

## 3. v2.0 一句话结构

```text
agent-os/        = 共享主仓库
agent-os-local/  = 本机私有目录
```

主仓库负责：配置、技能、知识、共享记忆元数据、工具、迁移脚本。

本机私有目录负责：L3 原文、向量库、缓存、原始素材和待投递素材。

## 5. v2.0 正式数据流

### 知识流

v2.0 采用“双入口汇聚到 Inbox”：

- 入口 A：标准化内容直接写入 `03_knowledge/00_inbox/`
- 入口 B：分类目录内容由 `collect_to_inbox` 汇聚到 `00_inbox/`
- 统一出口：`inbox_refine` 提纯归档

### 记忆流

```text
WorkBuddy 工作日志 / 系统画像 / 上轮摘要
    -> daily_digest.py
    -> facts.db
    -> keyword_index.json / ChromaDB
    -> 原文写入本机 raw/
```

### 工具流

`05_tools/` 是工具层，不默认等于技能层。

## 7. 恢复步骤

```bash
cd ~/workbuddy-agent-os/agent-sync/00_bootstrap
bash init.sh
bash apply-config.sh
bash import_skills.sh

~/.workbuddy/binaries/python/envs/agent-os/bin/python3 \
  ~/workbuddy-agent-os/agent-sync/02_skills/memory_manager/bootstrap_from_memory.py \
  --root ~/workbuddy-agent-os/agent-sync
```

手动安装项：

- WorkBuddy
- 坚果云
- Obsidian（按需）
- oMLX 与模型

## 8. v2.0 不做什么

以下内容已经明确延后：

- `collect_from_local.py`
- `skill_scanner.py`
- `SKILL_CARD.yaml` 全量改造
- 工具 manifest / 自动化安装体系
- 更细粒度的多机记忆隔离策略
- 基于 `agent-os-local/materials/` 的全新单入口采集体系

## 9. 现在应该怎么理解这个仓库

如果只看一句话：

> 这是一个已经从原形长成“可运行增强版”的 AgentOS 仓库，v2.0 的任务不是继续发散，而是先把当前这版冻结、讲清、可恢复。
