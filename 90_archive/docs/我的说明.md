B. 05_tools/ 下：skill_scanner.py（技能身份证扫描器）

让你在任何一台机器上运行一次，就知道哪些技能就绪、哪些缺依赖：

```python
#!/usr/bin/env python3
"""扫描所有 SKILL_CARD.yaml，生成技能状态报告"""
import os
import yaml
from pathlib import Path

SKILLS_DIR = Path.home() / "agent-os" / "02_skills"

def scan():
    print("=" * 60)
    print("AgentOS 技能状态报告")
    print("=" * 60)
    for skill_dir in sorted(SKILLS_DIR.iterdir()):
        if not skill_dir.is_dir():
            continue
        card_path = skill_dir / "SKILL_CARD.yaml"
        if not card_path.exists():
            print(f"  ⚠️  {skill_dir.name} — 无 SKILL_CARD.yaml（外部技能或待补充）")
            continue
        with open(card_path) as f:
            card = yaml.safe_load(f)
        s = card["skill"]
        o = card.get("ownership", {})
        print(f"  ✅ {s['name']} (v{s['version']}) 主理: {o.get('master_editor', '未知')}")
    print("=" * 60)

if __name__ == "__main__":
    scan()
```

放在 05_tools/skill_scanner.py，用 AGENTOS_PYTHON 运行即可。
