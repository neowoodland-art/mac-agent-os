# 本机标识（HOST_ID）

## 当前主机名（唯一标识）

```
my-macbook_macOS14.4_16GB_master
```

## 命名规则

格式：`{设备名}_{系统版本}_{内存}_{角色}`

| 字段 | 说明 | 示例 |
|------|------|------|
| 设备名 | 自定义设备名称 | my-macbook / office-pc |
| 系统版本 | OS+版本号 | macOS14.4 / Win11 |
| 内存 | 总内存 | 16GB / 32GB |
| 角色 | 当前角色 | master / maintainer / node |

## 角色说明

| 角色 | 权限 | 职责 |
|------|------|------|
| `master` | 最高权限 | 审核inbox、维护知识库、管理技能 |
| `maintainer` | 写入权限 | 可直接写入协同目录 |
| `node` | 提交权限 | 只能通过inbox提交内容 |

## 角色切换

只需修改本文件中的角色字段（如 `node` → `master`），重启相关任务即可生效。
